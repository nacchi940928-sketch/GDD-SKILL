# 锦标赛对阵树 — UX 规范（L1 基底）

## 规范目标

定义对阵树类活动的界面架构与交互行为规范。视觉尺寸引用 `resolution_standard`，反馈引用 `interaction_feedback`。

## 界面架构预设（必填）

| 项 | 默认 |
|----|------|
| 入口 | HUD 活动入口 / 福利中心 Tab |
| 主界面（观众） | 全屏对阵树页 |
| 主界面（选手） | 全屏决斗/战斗页 |
| 活动展示 | 居中弹窗（公示期） |
| 竞猜（可选） | 对阵树内行内入口 + 押注弹窗 |
| 战报 | 叠加弹窗 |

**身份分流**：
- CONTESTANT：【前往】→ 决斗界面
- SPECTATOR：【前往】→ 对阵树界面

## 与全局画布及屏幕适配

> 分辨率与适配由 `resolution_standard` 统一定义。Bracket 布局在 9:20 画布内，不向黑边延伸。

## 状态机 — 对阵树节点

### PENDING

**触发**：节点创建或上一轮未到达  
**表现**：占位「?」或待定头像  
**禁止**：显示战报入口  

### IN_PROGRESS

**触发**：当前 phase 轮次 == node.round  
**表现**：显示「竞猜」按钮（若 enable_betting）；或仅展示对阵  
**禁止**：Completed 态按钮共存  

### COMPLETED

**触发**：winnerId != 0  
**表现**：胜者高亮；显示「战报」入口  
**禁止**：显示竞猜按钮  

**验收**：
- 同一节点不同时显示竞猜与战报
- 已押注时隐藏该轮所有竞猜按钮（项目 delta 可细化）

## 交互规则

| 操作 | 选手 | 观众 |
|------|------|------|
| 进入决斗界面 | ✅ | ❌ Tips 拦截 |
| 对阵树「你的决斗」Tab | ✅ | ❌ Tips |
| 竞猜押注 | 按项目 | ✅（若启用） |
| 查看进行中战斗积分 | ✅ | ❌ 结算后战报 |

## 表现规则

- Bracket 视觉：单败树形，round 自左向右或自上而下（L2 定稿）
- 节点连线：胜者晋级方向明确
- 倒计时：顶栏或入口展示 phase 剩余时间

## 异常规则

- 网络失败：Toast + 重试（继承 interaction_feedback）
- 阶段不允许的操作：行内 Tips，不弹全屏

## 验收标准

- [ ] 入口与身份分流符合架构预设
- [ ] 节点三态表现与禁止项无冲突
- [ ] 不重复定义分辨率与按钮反馈
