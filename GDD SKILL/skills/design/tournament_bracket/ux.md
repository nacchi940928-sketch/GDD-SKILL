# 单败淘汰赛对阵树 — UX 规范（框架 Skill）

## 规范目标

对阵树类活动的**界面架构模式**与节点交互行为规范。引用 `resolution_standard`、`interaction_feedback`，不定义具体界面名称与文案。

## 界面架构预设（模式）

| 模式 | 说明 |
|------|------|
| 入口 | L2 定：HUD / 活动中心 / 弹窗触发 |
| 参赛者主界面 | 全屏战斗流 |
| 观赛者主界面 | 全屏对阵树 |
| 公示 | 弹窗或全屏预览 |
| 扩展槽 UI | 由 extension_slots 驱动，L2 定义 |

**身份分流（双身份模式）**：
- CONTESTANT → 战斗主界面
- SPECTATOR → 对阵树主界面

## 与全局画布

> 布局在 `resolution_standard` 画布内；本 Skill 不定义分辨率。

## 状态机 — Bracket 节点（框架）

### PENDING

**触发**：节点未到达或轮次未到  
**表现**：占位/待定  
**禁止**：终态入口（战报等）

### IN_PROGRESS

**触发**：当前 Phase 轮次 == node.round  
**表现**：可进行轮次内操作（战斗入口 / 扩展槽入口，L2 定义）  
**禁止**：与 COMPLETED 态入口共存

### COMPLETED

**触发**：winnerId 已确定  
**表现**：胜者标识；终态入口（如战报）  
**禁止**：轮次内进行中入口

**框架验收**：同一节点不同时展示互斥入口。

## 交互规则（模式）

| 操作类型 | 参赛者 | 观赛者 |
|----------|--------|--------|
| 进入战斗主界面 | 允许 | L2 门控（通常禁止） |
| 对阵树内参赛者专属 Tab | 允许 | L2 门控 |
| 扩展槽（如 betting） | L2 定义 | L2 定义 |
| 进行中战斗数据可见性 | L2 定义 | L2 定义 |

## 表现规则

- Bracket 树形排布方向：L2 定稿
- 阶段倒计时：入口或顶栏展示剩余时间（字段 L2 定义）

## 异常规则

- 网络失败：继承 `interaction_feedback` Toast
- 阶段不允许的操作：行内 Tips

## 验收标准

- [ ] 身份分流符合架构模式
- [ ] 节点三态无互斥冲突
- [ ] 未重复定义分辨率与按钮反馈
