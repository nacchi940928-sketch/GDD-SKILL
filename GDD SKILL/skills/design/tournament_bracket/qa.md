# 锦标赛对阵树 — 测试规范（L1 基底）

## 规范目标

对阵树系统通用测试基线。L2 `02/验收标准/` 与 `03/验收场景.md` 展开项目用例。

## 测试范围

- 报名与身份
- 签位与机器人补位
- 阶段切换
- 节点状态与晋级
- 身份门控（选手/观众）
- 竞猜（若 enable_betting）

## 测试用例

### T-TB-001 自动报名

**前置**：registration_mode=auto，到达 registration_cron  
**步骤**：触发定时任务  
**验证**：选手/观众身份正确写入；对阵树快照生成  

### T-TB-002 身份锁定

**前置**：identity_lock_days=7，已报名  
**步骤**：模拟排名变化事件  
**验证**：P-07 类身份字段不变  

### T-TB-003 签位固定

**前置**：bracket_size=16，部分空缺  
**步骤**：robot_fill=true 执行签位  
**验证**：叶节点 16 个；签位与固定表一致  

### B-TB-001 观众进决斗

**前置**：role=SPECTATOR  
**步骤**：尝试进入决斗界面  
**验证**：拦截 + Tips  

### E-TB-001 签位失败回滚

**前置**：模拟签位异常  
**验证**：报名数据回滚；无脏快照  

## 自动化检查点

- phase 枚举转换与服务端定时任务日志一致
- BracketNode.status 仅合法枚举值
- COMPLETED 节点 winnerId 非 0
