# P5 编译验收 — 规范（Skill）

> **本文件是 Skill（知识与规范）**，不是提示词。  
> 执行请使用 `prompts/P5/P5-*.md` 中的提示词。

---

## 定位

P5 在 P3/P4 完成后，检查文档质量、执行编译、策划验收。**禁止手改 outputs/**。

## 编译命令

```bash
cd "GDD SKILL"
python tools/compile.py 案例/{功能名} --workflow workflows/{项目}.workflow.json
```

产出 `outputs/{功能名}/`：
- 程序包.md
- 测试包.md
- 策划包.md
- compiled.json

## 职能分轨检查

| 错轨内容 | 应在 |
|----------|------|
| 交互视觉细节堆在 规则/ 或 01 | UI交互/ 或 ux.md |
| 协议字段散落在 UI交互/ | 数据源/ |
| 测试用例只在 02 不在 03 | 03/验收场景.md |
| 业务规则伪代码只在 03 不在 02 | 02/规则/（03 写全但 02 要有编号） |

## 策划验收清单

- [ ] 03 可独立开发，无外部跳转
- [ ] P-xx 全部登记，04-01 程序已确认命名
- [ ] 状态机无歧义，含服务端/客户端伪代码
- [ ] 继承现网 / excluded_systems 边界清晰
- [ ] skill_configs 与 02/规则 数值一致
- [ ] 04 策划必填项已完成（02 配置数值、03 UI文案等）

## 变更回流

```text
需求变更 → 改 02/03/04 或 L1 Skill → 重新 compile → 评审 outputs diff
```
