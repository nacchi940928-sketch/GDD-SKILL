## 公共铁律

1. **绝对自包含**：禁止跳转 01/02 才能开发
2. **02 → 03 映射**：每条 R-CHH-xxx 在 03 有对应「怎么实现」或附录追溯
3. **字段**：只用附录 A 已登记 P-xx
4. **implementation_data**：审计产出在 **附录 D**，不在 02
5. **config_table**：程序态表在附录 E 或各章「数据来源」
6. **工程真源**：P3 开始前须有 `02.5-工程真源摘录.md`；禁止无来源编造 proto/表名；禁止读 `程序反馈/`
7. **02/03 一致**：03 终裁方、阶段时序**不得与 02 已定 R- 冲突**；冲突时改 03（P4.5 对账改 02 时须同步 03）
8. **P4.5 后全量核对**：决策稿回流后，须逐章对照 02 §3 与 03「怎么实现」
9. **禁止伪代码块**：03「怎么实现」用 **步骤列表 / 协议时序表**（发起方、消息、终裁方、失败分支）；**禁止** `FUNCTION`/`EMIT`/逻辑代码块
10. **章序对齐 §2**：03 `## N.` 顺序与 02 §2 主流程一致；计分类按 Phase 拆章（单轮结算 / 整局结算 / SD 分列，禁止合并为一章「计分」）
11. **类名/proto 来源**：Client 类名、proto 消息名须来自 **02.5 已绑定** 或标 Q-P；禁止无来源自造
