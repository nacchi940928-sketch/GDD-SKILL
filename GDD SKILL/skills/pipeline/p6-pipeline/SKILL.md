# P6 开发管线 — 规范（Skill）

> **本文件是 Skill（知识与规范）**，不是提示词。  
> 执行请使用 `prompts/P6/P6-*.md` 中的提示词。

---

## 定位

将 `03-功能点梳理` + `02-需求拆解` 转化为**后端/前端 AI 自动开发**所需的四件套文档。

## 仓库与产出路径

```text
server/design/{功能名}/
  ├── 需求文档.md
  ├── 设计方案.md
  ├── 开发方案.md
  └── 管线编排.md

client/design/{功能名}/
  ├── 需求文档.md
  ├── 设计方案.md
  ├── 开发方案.md
  └── 管线编排.md
```

## 四件套定义

| 文档 | 内容 |
|------|------|
| 需求文档 | 从 03 提取的本端任务范围、功能点列表、验收标准引用 |
| 设计方案 | 模块划分、类/服务结构、与现网复用关系 |
| 开发方案 | 具体实现步骤、文件清单、接口对接点 |
| 管线编排 | AI 管线任务序列、依赖顺序、输入输出 artifact |

## 后端输入

- `03-功能点梳理/`（主读）
- `02/数据源/`、`02/校验规则/`、`02/状态机/`（服务端部分）
- `workflows/*.json` skill_configs
- L1 `skills/frameworks/*/tech.md`

## 前端输入

- `03-功能点梳理/`（主读）
- `02/UI交互/`、`02/状态机/`（客户端）、`02/红点/`
- server 已交付的协议/字段命名（04-01 或 proto）
- L0 `resolution_standard`、`interaction_feedback`（引用，不重复写）

## 继承现网原则

| 标记 | 文档写法 |
|------|----------|
| 复用 | 只写对接点 + 调用方式 |
| 改动 | 写 delta + 影响范围 |
| 新增 | 完整规格 |

禁止对「继承现网」模块重写完整需求。

## 管线编排任务格式

```markdown
| 序号 | 任务 | 输入 | 输出 | 依赖序号 | 对应03文件 |
|------|------|------|------|----------|------------|
| 1 | | | | — | |
```

## Prompt 索引

| 提示词 | 产出端 | 产出 |
|--------|--------|------|
| P6-1-后端管线编排.md | server | 四件套 |

## 推荐顺序

```
compile.py 生成程序包
  → P6-1 后端（先后端）
  → 后端交付协议
  → P6-2 前端
  → P6-3 核对继承现网模块（可与 P6-1/2 合并执行）
```
