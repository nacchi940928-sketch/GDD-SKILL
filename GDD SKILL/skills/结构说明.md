# GDD SKILL 结构说明

> **位置**：`skills/结构说明.md`  
> **可移植包**：只复制 **`skills/`** 文件夹；见 [README.md](README.md)。

---

## 1. 两层路径

```text
WORKSPACE_ROOT/                  ← Cursor 工作区根（skills 的父目录）
├── skills/                      ★ 唯一需要复制到其他项目的文件夹
│   ├── README.md
│   ├── gdd-decompose/           → 复制到 .cursor/skills/ 后成为 /gdd-decompose
│   ├── gdd-norm-feedback/
│   ├── prompts/
│   ├── pipeline/
│   ├── templates/
│   ├── tools/
│   ├── workflows/
│   ├── frameworks/、tech/、ux/
│   └── install-cursor.ps1
├── 产出/{功能名}/               L2 交付（不随 skills 包复制）
├── 源文档/                      各项目自备
└── .cursor/skills/              由 install-cursor.ps1 从 skills/gdd-* 复制生成
```

| 名称 | 含义 |
|------|------|
| **SKILLS_ROOT** | `skills/` 目录本身 |
| **WORKSPACE_ROOT** | `skills/` 的父目录 |

---

## 2. 执行模型

```text
.cursor/skills/gdd-decompose/SKILL.md    编排（Cursor 斜杠命令）
        ↓
skills/prompts/                          逐步 Prompt 正文
        ↓
skills/pipeline/                         格式铁律
        ↓
WORKSPACE_ROOT/产出/{功能名}/            交付物
```

---

## 3. gdd-decompose 文件夹（Cursor 规范）

```text
skills/gdd-decompose/
├── SKILL.md          ⭐ 必需
├── reference.md      管线步骤表
├── examples.md       对话示例
├── scripts/          compile 转发
└── README.md
```

`gdd-norm-feedback/` 结构相同（无 scripts/）。

---

## 4. 复制到其他项目

### 必带

整棵 **`skills/`** 目录。

### 目标项目布局

```text
你的项目/
├── skills/              ← 粘贴
├── 产出/                ← 新建
└── .cursor/skills/      ← install-cursor.ps1 生成
```

### 不能只复制

| 只复制 | 结果 |
|--------|------|
| 仅 `gdd-decompose/` | ❌ 缺 prompts、pipeline |
| 仅 `.cursor/skills/` | ❌ 同上 |
| 整棵 `skills/` + 安装 Cursor | ✅ |

---

## 5. 管线阶段（P0～P7）

Prompt：`skills/prompts/` · 铁律：`skills/pipeline/` · 产出：`产出/{功能名}/`

| 阶段 | 产出 |
|------|------|
| P1 | `01-…/原始策划案.md` |
| P2 | `02-需求拆解.md` |
| P2.5 | `02.5-工程真源摘录.md` |
| P3 | `03-功能点梳理.md` |
| P4 | `04-待策划补充/` |
| P5 | `开发文档/` 三包 |

详见 [gdd-decompose/reference.md](gdd-decompose/reference.md)。

---

## 6. 编译

```bash
python skills/tools/compile.py 产出/{功能名} --workflow skills/workflows/{项目}.workflow.json
```
