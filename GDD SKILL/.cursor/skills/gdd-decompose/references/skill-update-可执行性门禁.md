## 2. P0 决策阻塞（典型）

命中任一 → 完整性检查标 **P0**，**禁止进 P2**：

1. 无 **做/不做** 且无【待确认】
2. 主流程 **时序歧义**（轮流/同时 矛盾）
3. 竞争/排序/计时 **无终裁方**
4. docx **配置/道具表仅摘要**，无行级数据
5. 多执行方职责完全未提及

Agent **不得**用推断默认闭合 P0。
