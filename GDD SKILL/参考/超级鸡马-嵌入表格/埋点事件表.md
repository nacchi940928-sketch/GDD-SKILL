# 埋点事件表

## Sheet: YyrBTU

| 事件 | 触发时机 | 上报参数 |
| match_start | 开始匹配 | 当前段位、MMR值 |
| match_success | 匹配成功 | 匹配耗时、当前地图ID、匹配到的玩家数量、各玩家段位 |
| match_cancel | 玩家取消匹配 | 取消时的匹配耗时 |
| round_start | 每轮开始 | 当前轮次（1-12）、参与玩家数 |
| crate_open | 玩家打开木箱拾取道具 | 轮次、被拾取的道具ID列表 |
| prop_place_success | 成功放置道具 | 道具ID、放置坐标、放置耗时 |
| prop_place_fail | 放置失败 | 道具ID，倒计时结束时的放置坐标 |
| run_start | 跑酷阶段开始 | 轮次、场上道具总数 |
| player_death | 玩家死亡 | player id，死亡原因（陷阱ID/环境/坠落）、死亡坐标、存活时长 |
| player_finish | 玩家到达终点 | player id，到达名次、耗时、是否携带金币 |
| round_end | 单轮结束 | 当前轮次、总完成耗时、得分明细 |
| too_easy | 触发 Too Easy | 当前轮次 |
| sudden_death_start | 进入平局加赛 | 并列玩家人数、当前轮次 |
| sudden_death_end | 加赛结束 | 获胜玩家ID、加赛耗时 |
| match_end | 整局结束 | 总轮数、是否触发加赛 |
| player_mmr | 段位变化时 | player id，变化后的 MMR 值与段位 |
| total_rounds_played | 每局结束后 | player id，累计完成的局数，累计完成的轮数 |
