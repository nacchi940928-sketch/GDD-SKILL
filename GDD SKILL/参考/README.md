# 参考 — 策划原始输入

本目录存放**尚未结构化的策划源材料**，不是规格交付目录。

## 放什么

| 类型 | 示例 |
|------|------|
| 策划 docx / ppt | `竞技场高级赛（纷乱的群殴锦标赛）活动优化.docx` |
| 会议纪要、口述整理 | `xxx-会议纪要.md` |
| 竞品截图说明 | `竞品-xxx.md` |

## 不放什么

| 禁止 | 应放位置 |
|------|----------|
| 01 定稿 | `案例/{功能名}/01-原始策划案/{功能名}/原始策划案.md` |
| 02/03/04 产出 | `案例/{功能名}/` 对应阶段目录 |
| 编译产出 | `outputs/{功能名}/` |

## 如何使用

1. 策划将 docx 放入本目录（或指定路径 @ 给 Agent）
2. **P1-1** `@参考/xxx.docx` → 产出 `案例/{功能名}/01-原始策划案/{功能名}/原始策划案.md`
3. **P2 及以后** 只 @ `原始策划案.md`，不再 @ docx

详见 [使用指导.md](../使用指导.md)。
