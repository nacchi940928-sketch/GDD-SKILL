| 样例 | 说明 |
|------|------|

## 与 `产出/` 的区别

| | `案例/` | `产出/` |
|--|---------|---------|
| 用途 | 对照、文档示例 | **真实项目交付**（01~04 + logs） |
| workflow | 可指向此处（样例） | **应指向此处** |
| 新建功能 | 一般不在这里建 | **在这里建** |
