4.3 对阵树数据结构（建议）

每个赛区一棵树，节点字段【待程序补充】至少包含：


| 字段（业务） | 说明 |
| round | 1=16进8, 2=8进4, 3=半决赛, 4=决赛 |
| matchIndex | 该轮场次序号 |
| slotLeft / slotRight | 选手 ID 或机器人 ID |
| winnerId | 胜方 |
| status | 未开始 / 进行中 / 已结束 |
| isRobot | 是否机器人 |
| displayScore | 展示用结算分 |

填充顺序：按上表 M1→M8 顺序写入叶子节点；胜者向父节点推进。
