# 6.2 竞猜币

6.2 竞猜币


| 项 | 规则 |
| 用途 | 锦标赛商店兑换 |
| 来源 | 仅积分转化 |
| 保留 | 永久，不随期清零 |
| 转化 | 第 6 天（结算阶段）：持有积分 1:1 → 竞猜币（P-20 可配）；积分清零 |
| 动画 | 全部比赛结束后首次进界面播放；当期未登录则下期不补播 |

功能点

发放时点与「七日活动日程表」一致：第 2–5 天每日 UTC0 各发 200；第 1 天不发；第 6–7 天不再发

转化时点：第 6 天（结算阶段）积分 1:1 转竞猜币；转化后积分余额必为 0

竞猜积分信息栏（icon + 数量）在以下界面样式与数据一致：对阵树、决斗、战报弹窗、竞猜主/押注/记录、锦标赛商店

离线玩家轮次到点仍发放；多轮未登录后只弹一次发放动画

转化动画：全部比赛结束后首次进界面播放；当期未登录则下期不补播

数据来源


| 读写 | 业务数据 | 程序字段 | 用途 |
| 读/写 | 当期竞猜积分 | P-16 | 押注、信息栏 |
| 读 | 累计获得（展示） | P-17 | 发放动画 |
| 读/写 | 竞猜币 | P-21 | 商店 |
| 读 | 发放额 / 轮次 | P-18、P-19 | 配表 |
| 读 | 转化比例 | P-20 | 第 6 天 |

怎么实现

通用规则

每期开始（周一 UTC0 新一期）服务端清零 P-16；P-21 永久保留。

第 2–5 天每日 UTC0 服务端增加 P-18（默认 200）；客户端首次进活动弹动画并展示 P-17。

第 6 天结算：剩余 P-16 按 P-20（默认 1:1）转入 P-21，积分必清零。

在「信息栏」上

上述 7 类界面共用同一组件：读 P-16，样式一致，只读不可点（押注在竞猜弹窗改余额）。

押注成功、结算、转化后推送或下次拉取刷新数量。

在「动画」上

发放：每轮首次进活动界面触发；离线累积多轮仍只播一次。

转化：决赛结束后的结算阶段，首次进界面触发；跨期不补播。

程序实现分工


| 事项 | 客户端 | 服务端 | 备注 |
| UTC0 发放 / 清零 | — | ✓ | P-18、P-19 |
| 第 6 天转化 | — | ✓ | P-20 |
| 信息栏组件 | ✓ 复用 | ✓ 下发 P-16 | 7 界面 |
| 发放/转化动画 | ✓ | ✓ 触发标记 | P-17 |
| 竞猜币持久化 | ✓ 展示 | ✓ 账户 | P-21 |
