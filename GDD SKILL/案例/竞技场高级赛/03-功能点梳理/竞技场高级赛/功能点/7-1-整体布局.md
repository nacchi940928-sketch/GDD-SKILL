7.1 整体布局


| 图上标注 | 表现 | 数据 |
| 竞猜积分信息栏 | icon + 数量 | P-16 |
| 比赛奖励统计 / 竞猜提示文本 | 选手：钻石+五档；观众：引导文案 | P-07、P-28 |
| 已下注标识 | 头像上「已下注」 | P-27 |
| 商店入口 / 竞猜入口（全量） | 右下圆形按钮 | 跳转锦标赛商店 / 竞猜系统 |
| 竞猜入口（精确场次） | 节点下「竞猜」文字 | 跳转竞猜系统并定位场次 |
| 战报入口（精确场次） | 已结束节点 | 跳转战斗记录弹窗 |


| 子图状态 | 表现 |
| 已完成战斗 | 节点显示战报/记录按钮 |
| 即将开始 | 节点显示竞猜按钮 |
| 完成押注后 | 支持对象头像已下注标识 |
| 观众点决斗 Tab | Tips：无决斗信息 |

框架结构（沿用现网锦标赛 Tab，在其上叠加新元素）：


| 区域 | 内容 |
| 顶栏左 | 竞猜积分信息栏（icon + 数量 P-16） |
| 顶栏中 | Tab：「你的决斗 - {当前轮次名}」 | 「锦标赛」 |
| 顶栏右 | 帮助 i |
| 奖励/引导条 | 选手：「你的锦标赛奖励」+ 进度条（如 7600/27600）+ 五档宝石；观众：竞猜引导句 |
| 中央 | 对阵树 Bracket（排布见下文 7.2） |
| 底栏 | 返回；回合结束倒计时；右侧 商店、竞猜（全量） 等 |
| 左侧 | 截图/相机（若现网有则保留） |
