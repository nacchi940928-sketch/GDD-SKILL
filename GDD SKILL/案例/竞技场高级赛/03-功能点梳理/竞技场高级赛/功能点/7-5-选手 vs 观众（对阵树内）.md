7.5 选手 vs 观众（对阵树内）

与上文 **「选手 vs 观众（全局行为矩阵）」**一致。补充：

观众点「你的决斗」Tab → Tips：无决斗信息（不切换内容）。

轮次结算动效（胜/负/晋级/奖励档位/选手结算奖）维持现网。

功能点

Bracket 节点数与「赛区与 16 强签位」一致：8 场 → 4 → 2 → 1

战报/竞猜/已下注互斥逻辑

选手/观众顶栏差异

观众决斗 Tab 仅 Tips

底栏商店、竞猜（全量）、倒计时与现网锦标赛框架兼容

| 读 | 奖励进度 | P-28 | 选手顶栏 |
| 读 | 已押注标记 | P-27 | 节点标签 |

怎么实现

通用规则

沿用现网锦标赛 Tab 框架，叠加 docx 标注的新增元素（顶栏积分、底栏入口、节点按钮）。

节点状态按 7.3 状态机渲染；同一节点竞猜与战报互斥。

选手顶栏展示 P-28；观众隐藏奖励条、展示竞猜引导文案。

在「Bracket」上

读 P-10 按 7.2 倒金字塔排布；未完成轮次显示 ?。

当前轮进行中：节点下显示「竞猜」→ 打开竞猜系统并定位场次。

已结束：显示战报入口 → 打开战斗记录弹窗（单场）。

在「入口」上

右下圆形按钮：商店、竞猜（全量，默认当前轮）。

已押注（P-27）：支持对象头像标签 + 隐藏该轮全部竞猜按钮。

8. 决斗界面增强

涉及界面 / 系统模块


| 模块 | 本功能点在此的表现 |
| 决斗界面（1v1） | 现网对战 + 新增顶栏/底栏 |
| 活动【前往】 | 仅选手可达 |
| 商店 / 竞猜 | 右下圆形入口 |

UI 原型

注意：决斗界面是 1v1 对战布局（中间「对战」、左右双方、底部「战斗！」），不是对阵树 Bracket。


| 图上标注 | 表现 | 数据 |
| 竞猜积分信息栏 | 顶栏 icon + 数量 | P-16 |
| 对战鸟力信息 | 双方 icon + 实时数值 | P-29 |
| 战斗奖励统计 | 本回合奖励（沿用现网） | — |
| 商店入口 / 竞猜入口（全量） | 右下圆形按钮 | 跳转锦标赛商店 / 竞猜系统 |
| 战斗按钮 | 「战斗！」（沿用现网） | — |
| 胜负关系提示特效 | 领先/落后/出局/冠军（沿用现网） | — |

可见性：仅选手可进；进行中双方战斗积分可见（观众不可进，规则见「选手 vs 观众」表）。

功能点

顶栏展示竞猜积分信息栏（P-16），与对阵树等同组件

右下新增商店、竞猜（全量）圆形入口，跳转逻辑与对阵树一致

对战鸟力 P-29、战斗按钮、「战斗！」、领先/落后/出局/冠军特效沿用现网

观众无法进入决斗界面（路由拦截或【前往】不分流至此）

第 1 天公示期「战斗！」不可用（与活动阶段门控一致）

数据来源


| 读写 | 业务数据 | 程序字段 | 用途 |
| 读 | 竞猜积分 | P-16 | 顶栏 |
| 读 | 双方鸟力 | P-29 | 对战区 |
| 读 | 选手/观众 | P-07 | 进入权限 |
| 读 | 对战/结算 | 沿用现网 | 战斗流程 |

怎么实现

通用规则

不重写决斗核心：开局、计分、结算、晋级仍走现网「纷乱的群殴」。

在现网决斗 UI 上叠加顶栏 P-16 与右下商店/竞猜入口（布局见示意图）。

仅选手且非第 1 天可看到可点的「战斗！」。

在「决斗界面」上

进入时拉 P-16、P-29；进行中刷新双方实时战斗积分（选手可见，观众不可见）。

点击商店/竞猜打开对应弹窗，关闭后回到决斗界面。

战斗奖励统计区沿用现网本回合奖励展示。

9. 战报与战斗记录

涉及界面 / 系统模块


| 模块 | 本功能点在此的表现 |
| 战斗记录弹窗 | 单场结果只读 |
| 对阵树 | 已结束节点战报入口 |
| 竞猜记录 | 每条「战斗记录」按钮 |

UI 原型

战报弹窗复用 1v1 对战信息布局展示单场结果，但标题为「战斗记录」，不是决斗操作界面。


| 图上标注 | 表现 |
| 战斗记录标题 | 「战斗记录」 |
| 查看轮次信息 | 「X强晋级赛」 |
| 对战角色信息 | 头像、鸟力、名称、结算积分、被淘汰标识 |
| 竞猜积分信息栏 | icon + 数量 |
| 返回按钮 | 关闭弹窗 |

弹窗规格


| 项 | 内容 |
| 标题 | 战斗记录 |
| 副标题 | {X}强晋级赛（16/8/4/2 对应轮次） |
| 主体 | 左选手 vs 右选手：头像、鸟力、名称、结算积分 |
| 胜负 | 胜方标识；败方 失败蒙层（现网样式） |
| 底栏 | 竞猜积分栏 + 返回 |

入口

对阵树 已结束 节点的战报入口

竞猜记录每条上的 战斗记录 按钮

只展示单场；不展示整棵树。

功能点

标题为「战斗记录」，副标题为「{X}强晋级赛」，与节点轮次一致

展示双方头像、鸟力、名称、结算积分；败方失败蒙层（现网样式）

底栏：竞猜积分信息栏 + 返回；无战斗操作按钮

仅两个入口：对阵树已结束节点、竞猜记录条目

不展示 Bracket 全树；一次弹窗对应一场

数据来源


| 读写 | 业务数据 | 程序字段 | 用途 |
| 读 | 单场对战结果 | 【待程序补充】 | 弹窗主体 |
| 读 | 竞猜积分 | P-16 | 底栏 |
| 读 | 轮次名 | 与 P-10 节点 | 副标题 |

怎么实现

通用规则

弹窗复用 1v1 对战信息布局，但去掉「战斗！」等操作，标题改为「战斗记录」。

数据为已结算单场：展示最终积分，非进行中实时分。

观众通过战报查看战后结果（战前不可见战斗积分，见「选手 vs 观众」表）。

在「入口」上

对阵树：仅已结束节点显示战报 icon；点击带 matchId/轮次参数打开弹窗。

竞猜记录：每条已结算场次提供「战斗记录」，打开同规格弹窗。
