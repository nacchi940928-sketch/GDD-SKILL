# 枚举定义

## TournamentPhase

| 值 | 名称 | 日期 | 积分发放 |
|----|------|------|----------|
| 0 | NONE | — | — |
| 1 | ANNOUNCE | 第1天 | 不发 |
| 2 | BATTLE_16 | 第2天 | UTC0发200 |
| 3 | BATTLE_8 | 第3天 | UTC0发200 |
| 4 | BATTLE_4 | 第4天 | UTC0发200 |
| 5 | BATTLE_FINAL | 第5天 | UTC0发200 |
| 6 | SETTLE | 第6-7天 | 不发 |

## PlayerIdentity (P-07)

| 值 | 名称 | 来源 |
|----|------|------|
| 0 | NONE | — |
| 1 | PLAYER | 组内1-4名 |
| 2 | AUDIENCE | 组内5+名 |

## BracketNodeStatus

| 值 | 名称 | 视觉 | 可点击 |
|----|------|------|--------|
| 0 | NONE | — | — |
| 1 | PENDING | 双方头像 | 当前轮→竞猜按钮 |
| 2 | IN_PROGRESS | 正常头像 | 竞猜按钮 |
| 3 | COMPLETED | 胜方亮/败方X | 战报入口 |

## BetResult

| 值 | 名称 |
|----|------|
| 0 | NONE |
| 1 | WIN |
| 2 | LOSE |
