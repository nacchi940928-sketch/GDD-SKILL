# 锦标赛协议

> **L1 基底**: tournament_bracket（workflow: arena.workflow.json）
> **继承说明**: 见各条目标注「继承 R-TB-xxx」或「L2 delta」

---

## GetPhaseInfoReq / Rsp

> **继承 L1** GetPhaseInfo（当前阶段 + 倒计时）

### 响应

| 字段 | 类型 | 说明 |
|------|------|------|
| phase | int | TournamentPhase 枚举（见 枚举定义.md） |
| remaining_sec | int64 | P-14 当前阶段剩余秒数 |
| day_index | int | 期中日 1-7 |
| tournament_id | int64 | 当前赛区/期次 ID |

## GetTournamentInfoReq / Rsp

> **L2 delta**（活动入口聚合拉取，合并 Phase + Bracket + 玩家态）

### 响应

| 字段 | 类型 | 说明 |
|------|------|------|
| phase | int | TournamentPhase 枚举 |
| identity | int | P-07 1=选手/2=观众 |
| group_name | string | P-03 周练组名 |
| group_rank | int | P-06 组内排名 |

| guess_points | int | P-16 竞猜积分 |
| guess_coins | int | P-21 竞猜币 |
| reward_progress | object | P-28 奖励进度(选手) |
| remaining_sec | int64 | P-14 倒计时 |
| day_index | int | 期中日 1-7 |
| bet_marks | object | P-27 已押注标记 `{round → {matchId, targetId}}` |

## PlaceBetReq / Rsp

> **L2 delta**（`enable_betting=true`）

### 请求

| 字段 | 类型 | 说明 |
|------|------|------|
| match_id | int | 场次 ID |
| target_id | int | 支持对象（必须为对阵双方之一） |
| amount | int | 押注额（1~P-16） |

### 响应

| 字段 | 类型 | 说明 |
|------|------|------|
| result | int | 0=成功；非0=错误码 |
| new_points | int | 扣减后 P-16 |
| bet_mark | object | 写入后的 P-27 条目 |

**校验**: 见 V-003~V-005；阶段须 ∈ [BATTLE_16, BATTLE_8, BATTLE_4, BATTLE_FINAL]；该轮 P-27 不存在。

## PhaseChangePush

> **继承 L1** PhaseChangePush（阶段变更推送）

| 字段 | 类型 | 说明 |
|------|------|------|
| tournament_id | int64 | 赛区/期次 ID |
| old_phase | int | 变更前阶段 |
| new_phase | int | 变更后阶段（BATTLE_16/8/4/FINAL 等） |
| remaining_sec | int64 | 新阶段 P-14 倒计时 |
| day_index | int | 期中日 |

**触发时机**: 每日 UTC0 阶段切换；周一 UTC0 新一期 ANNOUNCE 开始。

**客户端处理**: 更新本地 phase → 刷新门控（战斗/竞猜按钮）→ 拉取或等待 BracketUpdatePush。

---

## BracketUpdatePush

> **继承 L1** BracketUpdatePush（节点状态/胜者增量更新）

| 字段 | 类型 | 说明 |
|------|------|------|
| tournament_id | int64 | 赛区/期次 ID |
| updates | BracketNode[] | 变更节点列表（matchId/round/status/winnerId/scoreLeft/scoreRight/slotLeft/slotRight） |
| version | int64 | 快照版本号 |

**触发时机**: 节点 status 变更（PENDING→IN_PROGRESS→COMPLETED）；胜者写入父节点；单场战斗结算后。

**客户端处理**: 合并 updates 到本地 P-10 → 刷新节点渲染（竞猜/战报按钮互斥）。

## PointsGrantPush

> **L2 delta**（每日 UTC0 竞猜积分发放，第 2-5 天）

| 字段 | 类型 | 说明 |
|------|------|------|
| tournament_id | int64 | 赛区/期次 ID |
| grant_amount | int | 本轮发放额（P-18，默认 200） |
| new_points | int | 发放后 P-16 |
| total_granted | int | 累计获得 P-17（动画展示用） |
| grant_anim_flag | int | 0=未播放 / 1=已播放 |

**触发时机**: ANNOUNCE→BATTLE_16 及后续各战斗日 UTC0 切换时。

**客户端处理**: 首次进活动界面且 grant_anim_flag=0 → 播放发放动画 → 上报已播放。

---

## PointsConvertPush

> **L2 delta**（结算阶段积分→竞猜币转化，第 6 天）

| 字段 | 类型 | 说明 |
|------|------|------|
| tournament_id | int64 | 赛区/期次 ID |
| converted_coins | int | 转化获得竞猜币（P-16 × P-20） |
| new_coins | int | 转化后 P-21 |
| convert_anim_flag | int | 0=未播放 / 1=已播放 |

**触发时机**: BATTLE_FINAL→SETTLE 切换，全部比赛结束后。

**客户端处理**: convert_anim_flag=0 → 播放转化动画；当期未登录则下期不补播。
