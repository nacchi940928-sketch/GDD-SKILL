# 锦标赛协议

## GetTournamentInfoReq / Rsp

### 响应

| 字段 | 类型 | 说明 |
|------|------|------|
| phase | int | TournamentPhase枚举 |
| identity | int | P-07 1=选手/2=观众 |
| group_name | string | P-03 周练组名 |
| group_rank | int | P-06 组内排名 |
| bracket | object | P-10 对阵树完整数据 |
| guess_points | int | P-16 竞猜积分 |
| guess_coins | int | P-21 竞猜币 |
| reward_progress | object | P-28 奖励进度(选手) |
| remaining_sec | int64 | P-14 倒计时 |
| day_index | int | 期中日1-7 |

## PlaceBetReq / Rsp

| 字段 | 类型 | 说明 |
|------|------|------|
| match_id | int | 场次ID |
| target_id | int | 支持对象 |
| amount | int | 押注额(1~P-16) |
| result | int | 0=成功 |
| new_points | int | 扣减后P-16 |
