# 对阵树节点状态机

> 每个 BracketNode（15个节点）独立维护状态。状态驱动客户端渲染和按钮显隐。

---

## 状态转移表

| 当前状态 | 触发事件 | 目标状态 | 条件 | 副作用 |
|----------|----------|----------|------|--------|
| PENDING | 轮次到达（phase切换到该轮） | IN_PROGRESS | 当前轮次 == node.round | 节点显示「竞猜」按钮；BracketUpdatePush(status=IN_PROGRESS) |
| PENDING | 玩家对该场押注成功 | PENDING | P-27写入 | 头像显示「已下注」标签；**隐藏该轮所有竞猜按钮**（不仅是此节点） |
| IN_PROGRESS | 战斗结束（胜者产生） | COMPLETED | winnerId != 0 | 胜者写入父节点 slotLeft/slotRight；竞猜结算触发；BracketUpdatePush(status=COMPLETED, winner_id, scores) |
| COMPLETED | — | — | 终态 | 显示「战报」入口（播放icon）；不再显示竞猜按钮 |

---

## 节点数据 (P-10 BracketNode)

```
{
  matchId: int,
  round: int,        // 1=R16, 2=QF, 3=SF, 4=FINAL
  matchIndex: int,   // 该轮场次序号
  slotLeft: int,     // 左位选手/机器人ID
  slotRight: int,
  winnerId: int,     // 0=未定
  status: enum,      // PENDING | IN_PROGRESS | COMPLETED
  isRobotLeft: bool,
  isRobotRight: bool,
  scoreLeft: int,    // 展示分（结算后）
  scoreRight: int,
  parentMatchId: int // 父节点ID（胜者上推目标）
}
```

## 客户端渲染逻辑

```
func renderNode(node):
    if node.status == PENDING:
        if node.round == currentRound && !P-27[node.matchId]:
            showButton("竞猜")  // 点击→竞猜主界面(定位场次)
        else:
            showPlaceholder("?")
    elif node.status == IN_PROGRESS:
        showButton("竞猜")  // 前提：P-27不存在
    elif node.status == COMPLETED:
        showLeftPlayer(node.slotLeft, isWinner=(node.winnerId==node.slotLeft))
        showRightPlayer(node.slotRight, isWinner=(node.winnerId==node.slotRight))
        showButton("战报")  // 点击→战斗记录弹窗
    
    if P-27[node.matchId] != null:
        showBadge("已下注", onAvatar=P-27.targetPlayerId)
        hideAllBetButtons(thisRound)  // 隐藏该轮所有竞猜
```
