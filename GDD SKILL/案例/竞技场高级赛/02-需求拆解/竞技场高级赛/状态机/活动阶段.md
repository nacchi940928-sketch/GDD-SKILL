# 活动阶段状态机

> **L1 基底**: tournament_bracket（workflow: arena.workflow.json）
> **继承说明**: 见各条目标注「继承 R-TB-xxx」或「L2 delta」

> **继承 R-TB-006** 阶段日程骨架（`phase_schedule`: 公示1天 + 战斗4轮 + 结算2天；每日 UTC0 切换）
> **L2 delta**: 战斗轮次命名为 `BATTLE_16` / `BATTLE_8` / `BATTLE_4` / `BATTLE_FINAL`（替代 L1 通用 `BATTLE_n`）

> 每日 UTC0 自动切换阶段。服务端权威驱动，客户端读 P-14 倒计时 + 本地门控。

## 服务端实现要点

```
// 每日UTC0定时任务
func onDailyUTC0():
    phase = getCurrentPhase()
    switch phase:
        case ANNOUNCE:  // 第1天→第2天
            transition(BATTLE_16)
            grantPoints(200)  // P-16 += P-18
            pushPhaseChange()
        case BATTLE_16:  // 第2天→第3天
            settleAllR16Matches()  // 结算16进8，晋级→QF
            settleBets(R16)        // 竞猜结算
            transition(BATTLE_8)
            grantPoints(200)
        ... (BATTLE_8, BATTLE_4 同理)
        case BATTLE_FINAL:  // 第5天→第6天
            settleFinalMatch()
            settleBets(FINAL)
            transition(SETTLE)
            convertPointsToCoins()  // P-16 × P-20 → P-21
            pushPointsConvert()
        case SETTLE:  // 第7天→下周一
            if isMonday():
                resetP16()
                startNewPeriod()  // 新一期：报名+签位
                transition(ANNOUNCE)
```
