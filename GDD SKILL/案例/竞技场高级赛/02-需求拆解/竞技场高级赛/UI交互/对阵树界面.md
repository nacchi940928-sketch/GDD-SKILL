## 组件行为

| 组件 | 可见条件 | 交互行为 | 状态变化 |
|------|----------|----------|----------|
| Bracket节点（进行中） | 当前轮次 | 显示双方头像+「竞猜」按钮 | 点击→竞猜主界面（定位场次） |
| Bracket节点（已结束） | 已结算 | 胜方亮/败方X+战报icon | 点击→战斗记录弹窗 |
| Bracket节点（未开始） | 未到轮次 | 显示 ? 占位 | 不可点击 |
| 「已下注」标签 | P-27已存在 | 头像上方展示 | 同时隐藏该轮所有竞猜按钮 |
| 「你的决斗」Tab | P-07=选手 | 可切换 | 观众→Tips"无决斗信息" |
| 商店入口 | 始终 | 打开锦标赛商店 | 关闭后回到对阵树 |
| 竞猜入口（全量） | 第2-5天 | 打开竞猜主界面 | 默认当前轮 |

## 节点按钮互斥逻辑

```
if node.status == PENDING:
    if node.round == currentRound && !P-27[node.round]:
        show("竞猜按钮")
    else:
        show("? 占位")
elif node.status == IN_PROGRESS:
    show("竞猜按钮")
elif node.status == COMPLETED:
    show("战报入口")
```

## 选手 vs 观众差异

| 区域 | 选手 | 观众 |
|------|------|------|
| 顶栏奖励条 | 钻石+五档进度(P-28) | 竞猜引导文案 |
| 「你的决斗」Tab | 可用 | Tips |
| 决斗界面入口 | 【前往】→决斗 | 【前往】→对阵树 |
| 战斗积分 | 实时可见 | 战前不可见，战后战报 |
