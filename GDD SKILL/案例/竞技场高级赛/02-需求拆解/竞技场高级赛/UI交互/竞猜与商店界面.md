# 竞猜与商店界面

> 来源: 策划案 §3.7, §3.8, 功能点梳理 §10, §11

---

## 竞猜主界面

| 区域 | 内容 |
|------|------|
| 标题 | 锦标赛竞猜 |
| 轮次 | X强晋级赛 |
| 提示 | 双倍积分说明 |
| 对阵 | 双方信息 + 【支持】按钮 |
| Tab | 竞猜（默认）/ 记录 |
| 场次切换 | 同轮次其他场次 |
| 底栏 | 积分信息栏 + 返回 |

## 押注弹窗

| 元素 | 说明 |
|------|------|
| 标题 | 参与竞猜 |
| 当前押注 | 当前押注的积分：{0} |
| 滑动条 | 快捷选额（min=1, max=P-16） |
| 微调按钮 | ±；到min/max时置灰 |
| 确认 | 提交押注→扣P-16→写P-27 |

## 竞猜记录Tab

| 元素 | 说明 |
|------|------|
| 空态 | 「您暂未参与本次锦标赛的竞猜！」 |
| 列表 | 按场次：轮次/猜中猜错/积分变化/对阵信息/淘汰标识 |
| 战斗记录 | 每条可点击→战斗记录弹窗 |

## 锦标赛商店

| 元素 | 说明 |
|------|------|
| 模板 | 复用竞技场商店UI换皮 |
| 标题 | 锦标赛商店 |
| 货币 | 竞猜币（P-21 icon+数值） |
| 商品 | 读取P-31配置表 |
| 交互 | 与竞技场商店一致（选中→确认购买→扣P-21→发奖） |

## 战斗记录弹窗

| 属性 | 值 |
|------|-----|
| 标题 | 战斗记录 |
| 副标题 | {X}强晋级赛 |
| 主体 | 左选手 vs 右选手：头像/鸟力/名称/结算积分 |
| 胜负 | 胜方标识；败方失败蒙层（现网样式） |
| 底栏 | 竞猜积分栏(P-16) + 返回 |
