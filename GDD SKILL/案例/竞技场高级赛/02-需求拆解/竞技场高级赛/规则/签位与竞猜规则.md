## 16强固定签位

### R-020 组代号映射

> **继承 R-TB-004**（固定签位表前置：组代号约定）

```
A/B/C/D = 赛区内第1/2/3/4个周练组
Ax = A组排名第x的玩家（x=1..4=选手）
```

### R-021 固定签位表 — 服务端填充逻辑

> **继承 R-TB-004**（`bracket_size=16` 固定签位表）

```
叶子节点[8]:
  M1: left=A1, right=B4   // 种子保护: A组第1 vs B组第4
  M2: left=B2, right=C3   // 交叉
  M3: left=B1, right=C4
  M4: left=C2, right=D3
  M5: left=C1, right=D4
  M6: left=D2, right=A3
  M7: left=D1, right=A4
  M8: left=A2, right=B3
```

### R-022 同组规避验证

> **继承 R-TB-004**（签位生成校验）

```
for m in [M1..M8]:
    assert getGroup(m.left) != getGroup(m.right)
    leftRank = getRank(m.left); rightRank = getRank(m.right)
    // 种子保护: 1号位对阵的是其他组的4号位
    assert (leftRank==1 implies rightRank==4) or (rightRank==1 implies leftRank==4)
```

### R-023 四轮淘汰推进

> **继承 R-TB-004** + **继承 R-TB-005**（单败晋级写入父节点）

```
QF(8进4): QF1=W(M1)vsW(M2), QF2=W(M3)vsW(M4), QF3=W(M5)vsW(M6), QF4=W(M7)vsW(M8)
SF(4进2): SF1=W(QF1)vsW(QF2), SF2=W(QF3)vsW(QF4)
 F(决赛):  F1=W(SF1)vsW(SF2) → 冠军
```
服务端每场结束 → 胜者ID写入父节点 `parentMatchId` → 推进状态。

### R-024 机器人补位

> **继承 R-TB-004**（`robot_fill=true`）

```
if 赛区实际选手数 < 16:
    robotCount = 16 - 实际选手数
    生成机器人（isRobot=true, 头像统一, 展示鸟力随机, 展示分=真人最低分×20%-30%随机）
    填充空缺叶子节点
```
机器人不参与真实战斗。机器人vs真人→真人自动胜出。机器人vs机器人→随机一方高积分晋级。

### R-025 对战继承

> **继承 R-TB-005**（继承现网「纷乱的群殴」战斗模块，只改签位来源）

沿用现网「纷乱的群殴」：异步对战，单局无尽模式最高分。决斗/晋级/奖励逻辑不变，只改签位来源+机器人+竞猜/商店。

## 竞猜规则

> **L2 delta**（`enable_betting=true` 启用竞猜子系统）

### R-030 参与资格

```
if player.tournament_id == 当前赛区ID:
    可参与竞猜  // 80人均可
```

### R-031 每轮限制 — 押注接口校验

```
押注校验:
  if phase not in [BATTLE_16, BATTLE_8, BATTLE_4, BATTLE_FINAL]: reject  // 非战斗日
  if P-27[该轮] 已存在: reject  // 每轮仅1次
  if now > 该轮UTC0截止: reject
  if amount < 1 or amount > P-16: reject
  if targetPlayerId not in [match.left, match.right]: reject  // 只能选对战双方
```

### R-032 结算

```
if bet.target == match.winner:
    P-16 += bet.amount * 2; bet.result = WIN
else:
    bet.result = LOSE  // 不返还
```

### R-033 已押注标记

服务端押注成功后写 P-27 = `{matchId → targetPlayerId}`。客户端读P-27渲染"已下注"标签，同时隐藏该轮所有竞猜按钮。

### R-034 第1天门控

客户端: `if phase==ANNOUNCE: 竞猜入口置灰/隐藏`。服务端: `if phase==ANNOUNCE: return ERR_BET_CLOSED`。
