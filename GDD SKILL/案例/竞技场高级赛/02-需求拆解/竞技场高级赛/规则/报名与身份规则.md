# 报名与身份规则

> **核心改动**: 取消主动报名 UI 与接口，改为周一 UTC0 自动报名。

---

## R-010 取消主动报名

**客户端**: 移除原报名按钮 UI 元素；移除报名请求调用代码；活动展示界面仅显示"已自动报名"状态。

**服务端**: 下线原报名接口（不再路由）；拒绝主动报名请求。

---

## R-011 自动报名时机

**触发**: 周一 UTC0 定时任务。

```
服务端定时任务:
  if now == 周一 00:00 UTC:
      读 P-03（周练组归属）+ P-06（组内排名）
      遍历每个玩家 → 执行 R-012/R-013 判定
      批量写入 P-07
      触发赛区划分（R-014）+ 签位生成（R-016）
      写入 P-10（对阵树快照）
```

| 读/写 | 数据 | 字段 | 用途 |
|--------|------|------|------|
| 读 | 周练组归属 | P-03 | 确定玩家所在小组 |
| 读 | 组内排名 | P-06 | 身份判定（1起） |
| 写 | 选手/观众 | P-07 | 入口分流+UI差异+门控 |

---

## R-012 选手判定

```
if P-06 in [1, 2, 3, 4]:
    P-07 = 1  // 选手
    P-28 = 初始化奖励进度
```

**选手权益**:【前往】→决斗界面；对阵树顶栏钻石+五档进度；「你的决斗」Tab可用；决斗界面可进入；实时战斗积分可见。

---

## R-013 观众判定

```
if P-06 >= 5:
    P-07 = 2  // 观众
```

**观众权益**:【前往】→对阵树界面；对阵树顶栏竞猜引导文案；决斗Tab→Tips"无决斗信息"；决斗界面拦截；可参与竞猜；战前积分不可见，战后战报查看。

---

## R-014 赛区组成

```
for (联赛ID, 档位ID) in 所有组合:
    同组合下取 4 个周练组
    合并为 1 个赛区 = 80人（16选手 + 64观众）
    独立淘汰赛、独立冠军、独立竞猜池
```

---

## R-015 身份整期不变

7天内P-07不因游戏事件改变。GM可手动修改（需audit日志）。下周一UTC0重新报名时覆盖。

---

## R-016 签位联动

报名事务提交成功后 → 调用签位生成（§4）→ 按固定签位表写16叶节点 → 不足16人机器人补位 → 写入P-10。签位生成失败则回滚报名事务。
