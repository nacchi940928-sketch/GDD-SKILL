# 积分与商店规则

> **L1 基底**: tournament_bracket（workflow: arena.workflow.json）
> **继承说明**: 见各条目标注「继承 R-TB-xxx」或「L2 delta」

> **本文件全部为 L2 delta**（`enable_betting=true` 启用的竞猜积分/竞猜币/商店子系统，不在 L1 通用规则内）

---

## 竞猜积分 (P-16)

### R-040 发放

```
第2-5天每日UTC0:
    for player in 赛区80人:
        P-16 += P-18  // 默认200，可配
        P-17 += P-18  // 累计获得
        grant_flag[player] = 本轮未播放
```
第1天不发，第6-7天不发（执行转化）。

### R-041 期初清零

```
新一期开始(周一UTC0):
    P-16 = 0  // 强制清零
```

### R-042 发放动画

客户端首次进活动界面时:
```
if grant_flag[player] == 本轮未播放:
    播放发放动画（展示 P-17 累计获得）
    grant_flag[player] = 已播放
```
离线多轮累积 → 只弹一次动画（flag为"未播放"→弹一次→标记已播放所有轮次）。

## 竞猜币 (P-21)

### R-050 转化

```
第6天结算阶段:
    converted = P-16 * P-20  // 默认1:1
    P-21 += converted
    P-16 = 0  // 必清零
```

### R-051 永久保留

P-21 不随活动期清零。新一期开始时保持不变。

### R-052 转化动画

```
if 全部比赛结束 and convert_anim_flag == 未播放:
    播放转化动画
    convert_anim_flag = 已播放
```
当期未登录 → 下期不补播。

## 商店

### R-060 货币

标题「锦标赛商店」，货币=P-21竞猜币。复用竞技场商店UI模板换皮。

### R-061 交互

```
打开商店 → 显示商品列表(P-31) → 选中商品 → 确认购买
  → 校验 P-21 >= price → 扣 P-21 → 发奖
  → 余额不足: 提示"竞猜币不足"
```

### R-062 限购

P-31 含 `limit_type`（无限/日/周/月）和 `limit_count`。服务端维护已购计数，购买时校验。
