# P4 提示词索引

规范：`skills/gdd/p4-planner-fill/SKILL.md`

## 定位

04 只收集**相对 L1 框架与已写 02/03 的 delta**——数值、文案、待确认项。  
L1 已定义的通用规则（如 Bracket 节点三态）**不应**重复进 04。

## 推荐顺序

```
P3 完成 → P4-1 生成 04 → 策划人工填写 → P4-2 验收 → P5
         ↑                                    │
         └──────── 未通过，更新 02/03/04 ───────┘
```

## 文件列表

| 提示词 | 执行者 | 产出 |

## 与 skill_configs 的关系

| 来源 | 内容 |
|------|------|
| `workflows/*.json` → `skill_configs` | 已确定的框架参数（如 bracket_size、registration_schedule） |

回填完成后，P4-2 验收通过方可进入 P5 编译。
