# P3 提示词索引

规范：`skills/gdd/p3-feature-spec/SKILL.md`

## 用法

1. **前置**：完成 P2 全部八个维度
2. 复制各文件「提示词正文」到 Agent
3. 替换 `{功能名}` 等占位符，@ 引用 01、02、03 已有文件
4. 按推荐顺序执行

## 推荐顺序

```
P3-1 阅读说明
  → P3-2 功能点拆分（可按章节分批）
  → P3-3 字段映射
  → P3-4 验收场景
  → P3-5 待确认事项
  → P3-6 Feature 对齐
```

## 文件列表

| 提示词 | 输出 |
|--------|------|
| P3-1-阅读说明.md | 03/{功能名}/0-阅读说明.md |
| P3-2-功能点拆分.md | 03/{功能名}/功能点/*.md |
| P3-3-字段映射.md | 03/{功能名}/字段映射.md |
| P3-4-验收场景.md | 03/{功能名}/验收场景.md |

| P3-6-Feature对齐.md | skills/design/{skill_id}/feature.md 任务表 |
