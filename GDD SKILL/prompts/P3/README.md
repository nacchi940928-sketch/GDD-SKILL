# P3 提示词索引

规范：`skills/gdd/p3-feature-spec/SKILL.md`

## 定位

**03-功能点梳理** 是程序（及 AI 开发管线）的**唯一主读文档**，必须自包含、可实现。  
L1 框架 Skill 提供骨架；**03 写全本项目业务细节**，不依赖「见 L1」。

## 用法

1. **前置**：完成 P2 全部八个维度
2. 复制各文件「提示词正文」到 Agent
3. 替换 `{功能名}` 等占位符，`@` 引用 01、02、03 已有文件、workflow
4. 按推荐顺序执行

## 推荐顺序

```
P3-1 阅读说明
  → P3-2 功能点拆分（可按章节分批）
  → P3-3 字段映射
  → P3-4 验收场景
  → P3-5 待确认事项
  → P3-6 Feature 对齐
```

## P3-6 与 L1 feature.md

| 文档 | 层级 | 内容 |
|------|------|------|
| `skills/design/{skill_id}/feature.md` | L1 框架 | 框架层任务清单（无项目路径） |
| `03/{功能名}/功能点/*.md` | L2 实例 | 本项目完整模块规格 |

P3-6 对齐时：检查 03 是否覆盖 L1 框架任务；**新增任务写进 03**，不往 L1 塞项目名词。
