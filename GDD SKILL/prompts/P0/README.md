# P0 提示词索引 — Part 1 策划辅助

> **Part 1（可选）**：帮策划**写**案。Part 2 规格交付见 [规格交付库.md](../规格交付库.md)。

规范：`skills/gdd/p0-discovery/SKILL.md`

## 定位

P0 = **策划创作辅助线**，帮助整理思路、定体验边界、选 L1 框架、产出 01 初稿。  
与 P2/P3 **规格交付线**分离：P0 不写 R/P 编号，不进程序管线。

```text
策划想法 / 口述 / 竞品参考
        ↓
P0-1 项目发现 → P0-2 GameDNA → P0-3 Skill 选型 → P0-4 玩法大纲 + 01 草稿
        ↓ 策划确认
P1 定稿 → P2 拆解 → P3 功能点 → …
```

## 推荐顺序

```
P0-1（对话或一次性提取）→ 策划确认 project.json
  → P0-2 → 策划确认 game_dna
  → P0-3 → 策划确认 Skill 选型
  → P0-4 → 策划审阅大纲与 01 草稿
  → P1-1 定稿为 原始策划案.md（或 P1-2 完整性检查）
  → P2
```

## 用法

1. 在 `案例/{功能名}/` 或新建功能目录下创建 `00-立项探索/{功能名}/`
2. 复制各文件「提示词正文」到 Agent
3. `@` 引用上一步产出、`skills/README.md`、参考 docx 等
4. **每步须策划确认**后再进下一步

## 与 P1 的分工

| 阶段 | 输入 | 输出性质 |
|------|------|----------|
| P0-4 | game_dna + skill选型 | 01 **草稿**，可多方案、多【待确认】 |
| P1-1 | docx / 01 草稿 / 口述 | 01 **定稿**，策划签字版 |
| P1-2 | 01 定稿 | gap 清单，不扩写 |
