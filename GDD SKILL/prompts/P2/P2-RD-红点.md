```

功能名：{功能名}
功能缩写：{功能缩写}

你的任务：为「{功能名}」生成 02-需求拆解 的「红点」维度。

【输出目录】
02-需求拆解/{功能名}/红点/红点规则.md
（入口多时可按入口拆文件）

RD-{功能缩写}-{序号}

- 红点位置（入口 id 或 UI 节点路径）
- 触发条件（何时亮起）
- 消除条件（点击 / 已读 / 业务完成）
- 检测方式（本地缓存 / 服务端 Push / 轮询）
- 层级聚合（子红点 → 父入口，如有）
- 数据依赖 P-xx
- 来源章节

【铁律】
- 触发与消除必须成对出现
- 禁止写具体像素、色值（归 UI交互/）
- 禁止「见原始文档」

【完成后自检】
- 每个入口红点是否都有消除条件？
- 层级聚合是否有循环依赖？

请直接创建/写入 markdown 文件，不要只输出大纲。
```
