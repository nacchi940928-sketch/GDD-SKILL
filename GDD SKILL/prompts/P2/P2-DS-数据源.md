## 提示词正文（复制以下内容）

```
请阅读我 @ 的原始策划案，以及（如有）workflow 与 L1 skill 文件。

功能名：{功能名}

你的任务：为「{功能名}」生成 02-需求拆解 的「数据源」维度。

【输出目录】
02-需求拆解/{功能名}/数据源/
  ├── 字段映射索引.md   ← 必须先产出
  ├── 配置表/
  ├── 协议/
  └── 枚举/枚举定义.md

【你必须做的事】
1. 从原始策划案中找出所有配置表、协议字段、运行时数据、枚举
2. 为每个字段分配全局唯一编号 P-01、P-02…，写入 字段映射索引.md
3. 索引表头：编号 | 业务含义 | 类型 | 来源表/协议 | 读写方 | 状态
4. 配置 / 运行时 / 协议分文件存放，枚举集中到 枚举/枚举定义.md
5. 若 L1 skill（如 tournament_bracket/tech.md）已有数据结构骨架，写「继承 {skill_id}」，只补充本项目字段名与 proto

【铁律】
- 先登记 P-xx，后续规则/状态机/03 禁止自创未登记字段名
- 禁止「见原始文档」
- 每条标注来源章节

【禁止】
- 不要写业务规则伪代码（归 规则/ 维度）
- 不要写 UI 布局（归 UI交互/ 维度）

【完成后自检】
- 字段映射索引是否覆盖原始案中所有数据项？
- 每个 P-xx 是否有类型与读写方？
- 是否与 L1 tech.md 骨架对齐？

请直接创建/写入上述目录下的 markdown 文件，不要只输出大纲。
```
