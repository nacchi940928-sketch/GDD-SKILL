# P2 提示词索引

`prompts/` 存放**可直接复制粘贴到 Agent 对话的提示词**。  
`skills/` 存放**规范、模板、可复用知识**（如 `skills/gdd/p2-decompose/SKILL.md`）。

## 用法

1. 打开对应维度的 `.md` 文件
2. 复制「提示词正文」代码块内的全文
3. 替换 `{功能名}`、`{功能缩写}` 等占位符
4. `@` 引用实际文件（原始策划案、L1 skill 等）
5. 发送给 Agent

## 推荐执行顺序

```
P2-DS（数据源，先登记 P-xx）
  → P2-R → P2-EX → P2-SM → P2-UI → P2-RD → P2-V → P2-T
```
