# 枚举定义 — 超级鸡马

## Phase（P-17 对局阶段）

| 值 | 名称 | 说明 |
|----|------|------|
| 0 | LOBBY | 选角/等待 |
| 1 | MATCHING | 匹配中 |
| 2 | CRATE_GRAB | 抢夺道具 |
| 3 | PROP_PLACE | 放置道具 |
| 4 | RUN | 跑酷 |
| 5 | ROUND_SETTLE | 单轮结算 |
| 6 | MATCH_SETTLE | 对局结算 |
| 7 | SUDDEN_DEATH | 加赛跑酷 |
| 8 | END | 结束 |

## MatchRelaxTier（P-14）

| 值 | 说明 |
|----|------|
| 0 | 同段位 |
| 1 | ±1 段位 |
| 2 | 任意段位 |

## PropPlaceFailReason

| 值 | 说明 |
|----|------|
| OVERLAP_PROP | 与已放置道具重叠 |
| OVERLAP_TERRAIN | 与地形重叠 |
| PROTECT_ZONE | 出生点/终点保护区 |
| ATTACH_INVALID | 附着条件不满足 |
| NO_ITEM | 未获得道具 |
| TIMEOUT | 倒计时结束 |

## DeathReason

| 值 | 说明 |
|----|------|
| TRAP_LETHAL | 陷阱致死部分 |
| ENV_TRAP | 地图原生陷阱 |
| FALL | 坠落出界 |

## ScoreType（单轮得分类型）

| 值 | 说明 |
|----|------|
| SURVIVE | 生存基础分 |
| SPEED | 速度分（第一名） |
| ACHIEVEMENT | 成就分（P-44） |
| COIN | 金币相关成就 |

**来源**：01 §2~§3
