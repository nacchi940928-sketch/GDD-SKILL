## 枚举与字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 道具 id（主键） |
| `name` | string | 显示名 |
| `item_type` | enum | **1**=平台 **2**=陷阱 **3**=机关 **4**=消耗品 **5**=拾取物 **6**=布置阶段道具 |
| `gravity_mode` | enum GravityMode | **0**=悬浮固定 **1**=掉落 **2**=跟随附着体；`need_attach=true` 且未填时按 **2** 解析 |
| `surface_friction_mult` | float | 站立面摩擦倍率 × **P-60**；默认 **1.0** |
| `need_attach` | bool | 是否必须附着放置 |
| `attachable` | bool | 是否可被其他道具附着 |
| `honey_connectable` | bool | 是否可被蜂蜜连接 |
| `trigger_mode` | enum | **0**=无 **1**=触碰 **2**=自动 **3**=靠近 |
| `trigger_period` | float | 周期/间隔（秒）；非周期填 **0** |
| `weight_by_round` | map | 各轮次出现权重 `{round: weight}` |
| `too_easy_weight_boost` | float | Too easy 触发后权重提升比例（如 0.2=+20%） |
| `trigger_desc` | string | 触发/行为描述（策划可读，程序可拆子表或脚本） |
| `remark` | string | 备注 |
| `prefab` | string | 资源路径 |

**推断已填**：`gravity_mode` / `surface_friction_mult` 按 01 与 docx 推断（见 [物理全量审计.md](../../规则/物理全量审计.md)）。**仍待填**：附着/权重/prefab → Q-D02b；全局物理 Const → Q-D09。
