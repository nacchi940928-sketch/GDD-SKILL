## 1. 通用属性列（表结构）

| 列名 | 分类/取值 | 说明 |
|------|-----------|------|
| 道具类型 | 1=平台 2=陷阱 3=机关 4=消耗品 5=拾取物 6=布置阶段道具 | |
| 是否受重力 | 悬浮 / 掉落 | 悬浮：不会掉落；掉落：存在掉落速度 |
| 是否附着放置 | bool | 附着放置的道具无需填「是否受重力」 |
| 是否可被附着 | bool | |
| 是否可连接附着物 | bool | 蜂蜜连接用 |
| 触发方式 | 无 / 触碰触发 / 自动触发 / 靠近触发 | 陷阱或机关如何被激活 |
