## AB2_ChickenHorseItem（道具表）

**一行一道具**，字段定义与 47 行数据见 [AB2_ChickenHorseItem.md](AB2_ChickenHorseItem.md)。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 主键 |
| name | string | 名称 |
| item_type | enum | 1=平台 2=陷阱 3=机关 4=消耗品 5=拾取物 6=布置阶段道具 |
| gravity_mode | enum GravityMode | 0=悬浮固定 1=掉落 2=跟随附着 |
| surface_friction_mult | float | × P-60 地面摩擦；默认 1.0 |
| need_attach | bool | 是否必须附着放置 |
| attachable | bool | 是否可被附着 |
| honey_connectable | bool | 是否可被蜂蜜连接 |
| trigger_mode | enum | 0=无 1=触碰 2=自动 3=靠近 |
| trigger_period | float | 周期/间隔（秒），非周期为 0 |
| weight_by_round | map | 各轮次出现权重 |
| too_easy_weight_boost | float | Too easy 权重提升比例 |
| trigger_desc | string | 触发/行为描述（不含可程序化数值） |
| remark | string | 备注 |
| prefab | string | 资源路径 |

【已提取】47 行；**gravity_mode / surface_friction_mult 已推断**（见 [物理全量审计.md](../../规则/物理全量审计.md)）。**仍待填**：附着/权重/prefab → Q-D02b。
