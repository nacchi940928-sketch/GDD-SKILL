# 配置表 — 超级鸡马

> 来源：01 §6 配置结构

## AB2_ChickenHorseItem（道具表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 道具 id |
| name | string | 名称 |
| weight_by_round | json/map | 各轮次出现权重 |
| need_attach | bool | 是否需附着放置 |
| gravity | enum | 受重力/不受重力/跟随附着 |
| honey_connectable | bool | 可否被蜂蜜连接 |
| too_easy_weight_boost | float | Too easy 触发后权重提升百分比 |
| trigger_period | float | 周期性触发间隔（秒），0=非周期 |
| trigger_fx_id | int | 触发表现 id |
| collider_lethal_mask | int | 致死碰撞层 bitmask |
| prefab | string | 资源路径 |

【已提取】完整道具清单与触发表现 — 见 [AB2_ChickenHorseItem.md](AB2_ChickenHorseItem.md)（47 项，docx 内嵌 Excel）。逐行权重/重力等数值仍待策划填表。
