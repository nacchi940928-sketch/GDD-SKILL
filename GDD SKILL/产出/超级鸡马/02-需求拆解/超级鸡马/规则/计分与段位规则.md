# 计分与段位规则 — 超级鸡马

## R-CHH-030 单轮积分结算

**触发**: R-CHH-025 或全员到达/死亡且无可操作

**检测位置**: 服务端  
**检测方式**: 阶段事件

```
P-17 = ROUND_SETTLE
alive_count = count(P-33)
if alive_count == len(P-16):
    too_easy = true
    全员 P-38 = 0
    提升部分道具 P-30 权重(too_easy_weight_boost)
else:
    for each player:
        if P-37 > 0: +生存分
        if P-37 == 1: +速度分
        +成就分 from P-44 行为统计
    P-38 = 明细
    P-39[player] += sum(P-38)
RoundSettleNtf
```

**来源**: 01 §3.6

## R-CHH-031 对局结束判定

**触发**: 单轮结算后

## R-CHH-032 排名与奖杯

**触发**: MATCH_SETTLE

**检测位置**: 服务端  
**检测方式**: 结算服务

```
按 P-39 降序排名

    P-41 = true
```

## R-CHH-033 段位奖励领取

**触发**: ClaimRankRewardReq

**检测位置**: 服务端

```
if reward_id not in P-56: reject
```
