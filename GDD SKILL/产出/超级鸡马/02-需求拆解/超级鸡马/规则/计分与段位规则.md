# 计分与段位规则 — 超级鸡马

## R-CHH-030 单轮积分结算

**触发**: R-CHH-025 或全员到达/死亡且无可操作

**检测位置**: 服务端  
**检测方式**: 阶段事件

```
P-17 = ROUND_SETTLE
reached_count = count(player where P-37 > 0)
if reached_count == len(P-16):   // Too easy：全员到达终点（见 Q-R01 R-08）
    too_easy = true
    全员 P-38 = 0
    P-40 += 1
    提升部分道具 P-30 权重(too_easy_weight_boost)
else:
    for each player:
        if P-37 > 0:
            P-38.survive += P-57
        if P-37 == 1:
            P-38.speed += P-58
        P-38.achievement += sum(本局已触发成就 × P-44.score)  // R-CHH-036~039
    P-39[player] += sum(P-38)
RoundSettleNtf
```

| 读/写 | 字段 | 用途 |
|--------|------|------|
| 读 | P-57 | 生存基础分 Const【待填 Q-D08】 |
| 读 | P-58 | 速度分 Const【待填 Q-D08】 |
| 读 | P-44 | 成就行为与分值【分值待填 Q-D07】 |
| 写 | P-38, P-39 | 单轮明细与累计 |

**来源**: 01 §3.6
