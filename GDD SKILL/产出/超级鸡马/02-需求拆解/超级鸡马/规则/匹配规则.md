# 匹配规则 — 超级鸡马

## R-CHH-001 段位优先匹配

**触发**: 玩家发起 MatchStartReq

**检测位置**: 服务端  
**检测方式**: 匹配队列入口

```
on MatchStartReq(player):
    读 P-07, P-08
    P-14 = 0  // 同段位
    入队 match_pool[P-07]
    P-13 = now()
    尝试 R-CHH-002
```

| 读/写 | 字段 | 用途 |
|--------|------|------|
| 读 | P-07, P-08 | 段位与 MMR |
| 写 | P-14, P-13 | 放宽阶段、开始时间 |

**来源**: 01 §2.1

---

## R-CHH-002 匹配放宽与成功

**触发**: 定时扫描匹配池 / 新玩家入队

**检测位置**: 服务端  
**检测方式**: 定时任务（建议 1s）

```
for each waiting player:
    elapsed = now() - P-13
    if 同 P-14 池内人数 >= 房间人数下限:
        组局 → MatchSuccessNtf(P-15, P-16, P-18)
        return
    if elapsed > T1 and P-14 == 0:
        P-14 = 1  // ±1 段位，合并相邻池
    if elapsed > T2 and P-14 == 1:
        P-14 = 2  // 任意段位
```

| 读/写 | 字段 | 用途 |
|--------|------|------|
| 读/写 | P-14 | 放宽阶梯 |
| 写 | P-15~P-18 | 对局初始化 |

【待确认】T1/T2 超时阈值、房间人数上下限。

**来源**: 01 §2.1

---

## R-CHH-003 匹配取消

**触发**: MatchCancelReq 或客户端断线

**检测位置**: 服务端  
**检测方式**: 请求入口

```
on MatchCancelReq:
    移出 match_pool
    上报 match_cancel(P-13 耗时)
```

**来源**: 01 §2.1、§9 埋点
