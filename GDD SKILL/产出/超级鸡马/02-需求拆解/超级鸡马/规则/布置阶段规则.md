# 布置阶段规则 — 超级鸡马

## R-CHH-010 木箱刷新与道具池

**触发**: 每轮 RoundStart（P-02 递增后）

**检测位置**: 服务端  
**检测方式**: 阶段切换事件

```
player_count = len(P-16)
base_items = 按 P-30 权重随机 player_count 个 P-26
extra_count = 按 P-31 权重抽 0~2
P-19 = base_items + extra_items
P-20 = now()
P-17 = CRATE_GRAB
下发 RoundStartNtf
```

| 读/写 | 字段 | 用途 |
|--------|------|------|
| 读 | P-02, P-16, P-30, P-31 | 轮次与权重 |
| 写 | P-19, P-20, P-17 | 木箱内容 |

**来源**: 01 §2.2、§3.2

## R-CHH-011 道具抢夺（先到先得）

**触发**: PickItemReq

**检测位置**: 服务端  
**检测方式**: 请求入口（P-22 时间戳排序）

```
if P-17 != CRATE_GRAB: reject
if P-26 not in P-19 或已被他人选走: reject
if now() - P-20 > P-03: reject  // 抢夺超时
P-21 = P-26
从 P-19 移除该 id
PickItemRsp success
```

未在 P-03 内确认的玩家：P-21 为空，放置阶段无道具可放。

**检测位置**: 服务端定时  
**检测方式**: P-20 + P-03 到期 → 全员进入 R-CHH-012 前置

**来源**: 01 §3.2

---

## R-CHH-012 放置倒计时与强制结束

**触发**: 抢夺阶段结束（倒计时到或全员已选/放弃）

**检测位置**: 服务端  
**检测方式**: 定时 / 状态机

```
P-17 = PROP_PLACE
start_place_timer(P-04)
when timer expire or all P-32:
    对未 P-32 且有 P-21 的玩家: 丢弃道具
    P-17 = RUN
    执行 R-CHH-020 跑酷开始
```

**来源**: 01 §2.2、§3.3

## R-CHH-013 道具放置合法性

**触发**: PlacePropReq

**检测位置**: 服务端（客户端预校验 + 红色闪烁）  
**检测方式**: 请求入口

```
if P-17 != PROP_PLACE: reject
if P-21 为空: reject NO_ITEM
if 坐标在出生/终点保护区(P-47,P-48): reject PROTECT_ZONE
if 与 P-23 重叠: reject OVERLAP_PROP
if 与地图地形重叠: reject OVERLAP_TERRAIN
if P-28 and 附着条件不满足: reject ATTACH_INVALID
if 附着超长: 截断超出部分，客户端红色预览
写入 P-23
P-32 = true
PlacePropRsp success
```

| 读/写 | 字段 | 用途 |
|--------|------|------|
| 读 | P-26~P-29, P-47, P-48 | 配置与保护区 |
| 写 | P-23, P-32 | 放置实例 |

**来源**: 01 §3.3

## R-CHH-014 蜂蜜粘合

**触发**: 放置蜂蜜类道具且邻接其他道具

**检测位置**: 服务端  
**检测方式**: PlacePropReq 后置

```
if 新道具为蜂蜜:
    for 邻接 prop in P-23:
        if prop.P-29: 建立物理链接组
        else: 允许摆放但链接不生效
```

**来源**: 01 §3.3
