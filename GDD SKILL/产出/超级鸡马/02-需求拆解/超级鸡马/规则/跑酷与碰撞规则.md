# 跑酷与碰撞规则 — 超级鸡马

## R-CHH-020 跑酷阶段开始

**触发**: 布置阶段结束 R-CHH-012

**检测位置**: 服务端  
**检测方式**: 阶段事件

```
P-17 = RUN
for each prop in P-23:
    cfg = AB2_ChickenHorseItem(P-26)
    switch cfg.gravity_mode:  // P-27
        Float(0):           固定 transform
        Fall(1):            启用掉落，速度 P-59
        FollowAttach(2):    继承附着体 gravity 状态
    若 honey 链接组: 按刚体组统一物理
重置 P-33=true, P-37=0, P-35=0（本局携带）
start_run_timer(P-05)
上报 run_start(P-02, len(P-23), P-18)
```

| 读/写 | 字段 | 用途 |
|--------|------|------|
| 读 | P-27 / gravity_mode | 道具重力模式 |
| 读 | P-59 | 掉落速度 Const |
| 读 | P-23~P-26 | 已放置实例 |

**来源**: 01 §2.3 · §3.3 · [物理全量审计.md](物理全量审计.md)

## R-CHH-021 角色移动与跳跃

**触发**: 客户端输入帧同步

**检测位置**: 客户端表现 + 服务端校验  
**检测方式**: 每帧 / 输入序列

```
移速基准 P-49
地面摩擦 = P-60 × standing_surface.P-64  // 站立 collider 对应道具 surface_friction_mult，默认 1.0
水平加速 P-61，减速 P-62，上限 P-63
松手后: 保留水平动量，按 P-62 与摩擦衰减
蓄力跳跃: hold_time capped by P-50 → 跳跃高度曲线
蹬墙跳: 贴墙 + jump → 反向速度，无次数限制
冲刺: P-52 冷却，距离 P-51，仅水平前后；无输入则朝向冲刺
蹲伏: 缩小 hitbox，P-43 冷却
```

所有角色性能一致，不读角色 id 差异。

| 读/写 | 字段 | 用途 |
|--------|------|------|
| 读 | P-49~P-52 | 移速/跳跃/冲刺 |
| 读 | P-59~P-63 | 跑酷物理 Const【待填 Q-D09】 |
| 读 | P-64 | 站立面摩擦倍率 |

**来源**: 01 §3.4 · [物理全量审计.md](物理全量审计.md)

## R-CHH-022 死亡判定

**触发**: 物理碰撞检测

**检测位置**: 服务端权威  
**检测方式**: 物理 tick

```
if player hitbox 接触 trap.lethal_collider:
    P-33 = false
    若 P-35 > 0: 生成 P-36 在死亡坐标，P-35=0
    PlayerDeathNtf(TRAP_LETHAL)
    客户端灰色遮罩
```

玩家间无碰撞。非致死 collider 不触发死亡。

**来源**: 01 §3.5

## R-CHH-023 金币拾取与传递

**触发**: 碰撞金币实体 / 死亡掉落

**检测位置**: 服务端  
**检测方式**: 碰撞事件

```

死亡: coin 悬浮在死亡点（P-36 gravity_mode=Float，不受 P-59），其他玩家可 PickCoin
到达终点(R-CHH-024): 仅当 P-33 且 P-37>0 时，金币分计入成就(P-44)
```
