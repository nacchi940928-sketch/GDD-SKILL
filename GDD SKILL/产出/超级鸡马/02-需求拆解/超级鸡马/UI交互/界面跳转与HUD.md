# 界面与跳转 — 超级鸡马

## 跳转图

```
[主界面]
  ├─ 开始游戏 → [选择角色] → [匹配中] → [对局场景]
  │                                      ├─ 布置 HUD（抢夺/放置）
  │                                      ├─ 跑酷 HUD
  │                                      └─ 单轮/总结算弹窗
  ├─ 选择角色（独立入口）
  └─ 段位/奖励
```

**来源**: 01 §4

---

## 主界面

| 元素 | 交互 | 差异 |
|------|------|------|
| 开始游戏 | 进入选角→匹配 | 首次红点 RD-CHH-001 |
| 段位入口 | 打开段位页 | 可领奖励红点 |

---

## 选择角色

| 元素 | 交互 | 差异 |
|------|------|------|
| 小鸟卡牌 | 点击选中已解锁 | 未解锁灰置；新解锁 RD-CHH-002 |
| 确认 | 带 P-11 进入匹配 | — |

---

## 对局 HUD — 布置

| 元素 | 交互 |
|------|------|
| 抢夺倒计时 | 只读 P-03 |
| 道具列表 | 点击确认 PickItemReq |
| 放置摇杆 | 吸附网格预览 |
| 确认键 | PlacePropReq |
| 非法反馈 | 红色闪烁 |

---

## 对局 HUD — 跑酷

| 元素 | 交互 |
|------|------|
| 游戏倒计时 | P-05 |
| 虚拟摇杆/跳跃/冲刺/蹲伏 | 输入 |
| 头顶金币 | P-35 |
| 死亡 | 灰色遮罩 |
