# 红点规则 — 超级鸡马

## RD-CHH-001 主界面-开始游戏

**位置**: 主界面玩法入口 icon

**出现**: P-54=false（首次进入玩法前）

**消失**: 完成任意一局对局后 P-54=true

**检测位置**: 客户端 + 服务端同步【待确认是否纯本地】

**来源**: 01 §8

---

## RD-CHH-002 选择角色-新解锁小鸟

**位置**: 小鸟卡牌右上角

**出现**: 小鸟 id ∈ P-10 新增且 id ∉ P-55

**消失**: 在角色界面点击浏览该小鸟 → P-55.add(id)

**来源**: 01 §8

---

## RD-CHH-003 段位奖励

**位置**: 段位进度右上角

**出现**: P-56 非空

**消失**: ClaimRankRewardReq 成功，P-56 移除对应 id

**来源**: 01 §8
