# 异常流程 — 超级鸡马

## EX-CHH-001 匹配超时仍无对手

**触发**: P-14 已为 2 且等待超过 T_max

**处理**:
```
选项 A: 继续等待 【待确认】
选项 B: 匹配失败提示，返回主界面
上报 match_success 失败或自定义事件
```

**来源**: 01 §2.1

---

## EX-CHH-002 抢夺阶段未选道具

**触发**: P-03 结束且 P-21 为空

**处理**: 跳过放置，P-32 视为 true，直接进入跑酷（该玩家本轮回合无布置贡献）。

**来源**: 01 §3.2

---

## EX-CHH-003 放置超时未确认

**触发**: P-04 结束且未 P-32

**处理**: 丢弃 P-21，不写入 P-23，上报 prop_place_fail(TIMEOUT)。

**来源**: 01 §3.3

---

## EX-CHH-004 跑酷中断线

**触发**: 玩家断线 during RUN

**处理**:
```
【待确认】重连窗口
默认: 视为 P-33=false 或 AI 托管直至 P-05 结束
```

**来源**: 【待确认】

---

## EX-CHH-005 全员 Too easy

**触发**: R-CHH-030 alive_count == 玩家数

**处理**: 全员 0 分；提升部分道具权重；UI 提示 Too easy。

**来源**: 01 §3.6

---

## EX-CHH-006 配置表缺失

**触发**: P-26 不在 AB2_ChickenHorseItem

**处理**: 服务端拒绝组局/刷新木箱，告警日志，降级为默认道具池【待确认】。

**来源**: 工程约束
