# 9-1 段位与奖杯

## 涉及模块

| 模块 | 类型 | 说明 |
|------|------|------|
| 段位系统 | 新增 | 奖杯升降段 |
| 段位奖励 | 新增 | 升段自动领+手动领 |
| 每周重置 | 新增 | cron |

## 功能点

- **P-09 奖杯**积累 → **P-07 段位**提升（阈值见 **P-45 / AB2_ChickenHorseLv**）；
- **升段**时自动发放对应 **reward**（若未在 **P-53**）；
- **奖杯扣除**可**掉段**；掉段后**已领奖励不可重复领**（UI 灰置）；
- **段位奖励**可领取列表 **P-56** → **ClaimRankRewardReq** → 更新 **P-53**，红点 RD-CHH-003 消失；
- **每周重置**（**P-46**）：段位重置到配置目标【待确认奖杯是否同步重置】。

对局排名奖励在对局结算（8-1）中增减奖杯。

## 数据来源

| P-xx | 用途 | 读/写 |
|------|------|-------|
| P-07~P-09 | 段位/MMR/奖杯 | 读写 |
| P-45~P-46 | 配置 | 读 |
| P-53~P-56 | 奖励领取状态 | 读写 |

## 怎么实现

### 服务端
- R-CHH-032 奖杯变动；R-CHH-033 领奖；R-CHH-035 定时重置；
- total_rounds_played / player_mmr 埋点。

### 客户端
- 段位进度条、奖励列表、灰置已领；
- 升段庆祝动画。
