# 7-1 单轮结算

## 涉及模块

| 模块 | 类型 | 说明 |
|------|------|------|
| 计分服务 | 新增 | 生存/速度/成就 |
| Too easy | 新增 | 全员存活特殊逻辑 |
| 单轮 UI | 新增 | 得分明细 |

## 功能点

跑酷结束进入 **ROUND_SETTLE**：

**正常**：对每个玩家
- 到达终点 → **生存基础分**；
- **P-37==1** → **速度分**；
- 统计本局行为 → **成就分**（**AB2_ChickenHorseScore**，9 项；**分值待填 Q-D07**，规则见 R-CHH-036~039）；
- **生存分**读 **P-57**、**速度分**读 **P-58**（**待填 Q-D08**）；
- 写入 **P-38**，累加 **P-39**。

**Too easy**：若全员到达终点 `count(P-37>0)==len(P-16)`（R-CHH-030，见 Q-R01 R-08）
- **全员 0 分**；
- 触发 **too_easy** 埋点；
- 提升部分道具 **too_easy_weight_boost** 权重（下轮木箱 R-CHH-010 使用）。

下发 **RoundSettleNtf** → 若 **P-39 < P-06** 且 **P-02 < P-01** 则 **P-02++** 下一轮；否则 **8-1 对局结算**。

## 数据来源

| P-xx | 用途 | 读/写 |
|------|------|-------|
| P-06 | 获胜分 | 读 |
| P-38~P-40 | 单轮/累计/too easy | 读写 |
| P-44 | 成就表（行为已定，分值 Q-D07） | 读 |
| P-57 | 生存基础分 | 读 |
| P-58 | 速度分 | 读 |

## 怎么实现

### 服务端
```
R-CHH-030:
  if count(P-37>0)==len(P-16): too_easy branch
  else: calc P-38 (P-57/P-58/P-44), P-39 += sum
  round_end 埋点
  R-CHH-031 判定对局是否结束
```

### 客户端
- 单轮结算弹窗：分项展示 P-38；
- Too easy 特殊文案/特效。
