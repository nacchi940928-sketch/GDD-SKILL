# 7-1 单轮结算

## 涉及模块

| 模块 | 类型 | 说明 |
|------|------|------|
| 计分服务 | 新增 | 生存/速度/成就 |
| Too easy | 新增 | 全员存活特殊逻辑 |
| 单轮 UI | 新增 | 得分明细 |

## 功能点

跑酷结束进入 **ROUND_SETTLE**：

**正常**：对每个玩家
- 到达终点 → **生存基础分**；
- **P-37==1** → **速度分**；
- 统计本局行为 → **成就分**（**AB2_ChickenHorseScore**，9 项：险象环生、漫长旅程、空中飞人、陷阱得分、反杀、助攻、唯一幸存者、翻盘、金币奖励；**分值列待策划填写**）；
- 写入 **P-38**，累加 **P-39**。

**Too easy**：若全员 **P-33** 存活到终点（或等价条件）
- **全员 0 分**；
- 触发 **too_easy** 埋点；
- 提升部分道具 **too_easy_weight_boost** 权重（下轮木箱 R-CHH-010 使用）。

下发 **RoundSettleNtf** → 若 **P-39 < P-06** 且 **P-02 < P-01** 则 **P-02++** 下一轮；否则 **8-1 对局结算**。

## 怎么实现

### 服务端
```
R-CHH-030:
  if all_alive: too_easy branch
  else: calc P-38, P-39 += sum
  round_end 埋点
  R-CHH-031 判定对局是否结束
```

### 客户端
- 单轮结算弹窗：分项展示 P-38；
- Too easy 特殊文案/特效。
