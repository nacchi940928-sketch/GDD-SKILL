# 11-1 埋点上报

## 涉及模块

| 模块 | 类型 | 说明 |
|------|------|------|
| 数据分析 SDK | 新增 | 客户端+服务端 |

## 功能点

按 01 §9 实现以下事件（参数见下表摘要）：

| 事件 | 关键参数 | 触发 |
|------|----------|------|
| match_start | P-07, P-08 | 发起匹配 |
| match_success | 耗时, 人数, 各段位 | 组局成功 |
| match_cancel | 取消耗时 | 取消匹配 |
| round_start | P-02, 人数 | 轮开始 |
| crate_open | P-02, 道具 ids, P-18 | 木箱打开/抢夺 |
| prop_place_success | P-26, 坐标, 耗时, P-18 | 放置成功 |
| prop_place_fail | P-26, 坐标, P-18 | 放置失败/超时 |
| run_start | P-02, 道具总数, P-18 | 跑酷开始 |
| player_death | player, 原因, 坐标, P-18 | 死亡 |
| layer_finish | player, 名次, 耗时, 金币次数 | 到终点 |
| round_end | P-02, 耗时, 得分明细 | 单轮结算 |
| too_easy | P-02, P-18 | Too easy |
| sudden_death_start/end | 人数/胜者/耗时, P-18 | 加赛 |
| match_end | 总轮数, 是否 SD | 对局结束 |
| player_mmr | 局数, 轮数 | 累计 |
| total_rounds_played | MMR, 段位变化 | 段位变动 |

各事件**目的/预期/结论**判定逻辑见 01 §9 原文，用于数据验证。

## 数据来源

- 运行时 P-xx 字段；对局上下文 P-15/P-18。

## 怎么实现

### 客户端
- 行为类事件（放置、死亡、取消）本地组装上报；

### 服务端
- 匹配、结算类事件以服务端为准，防作弊。
