# 3-1 木箱与道具抢夺

## 涉及模块

| 模块 | 类型 | 说明 |
|------|------|------|
| 木箱刷新 | 新增 | 每轮中央刷新 |
| 抢夺 UI | 新增 | 10s 倒计时、道具列表 |
| 抢夺仲裁 | 新增 | 先到先得 |

## 功能点

每轮 **P-02** 开始时，地图中央刷新**木箱**：
- 基础道具数 = 玩家人数，从 **AB2_ChickenHorseItem** 按 **P-30**（轮次权重）随机 **P-26**；
- 额外 **0~2** 个道具按 **P-31** 权重抽取；
- 结果写入 **P-19**，**P-20**=打开时间戳，**P-17**=CRATE_GRAB。

**抢夺阶段（P-03=10 秒）**：
- 所有玩家同时行动，点击确认道具 → **PickItemReq(P-26, P-22)**；
- 服务端按 **P-22** 时间戳先到先得；成功则 **P-21**=该道具，从 P-19 移除；
- **P-03** 结束后未确认者 **P-21** 为空，本轮回合无道具可放置。

## 数据来源

| P-xx | 用途 | 读/写 |
|------|------|-------|
| P-02 | 轮次 | 读 |
| P-03 | 抢夺时长 | 读 |
| P-19~P-22 | 木箱与选择 | 读写 |
| P-26~P-31 | 道具配置 | 读 |

## 怎么实现

### 服务端
```
RoundStart:
  P-19 = gen_items(P-30, P-31, player_count)
  P-20 = now(), Phase=CRATE_GRAB
  schedule(P-03) → end_grab()

on PickItemReq:
  V-CHH-002
  P-21 = P-26; remove from P-19
  crate_open 埋点
```

### 客户端
- 木箱开启动画；倒计时条；
- 道具 icon 可点；已被抢灰置；
- 失败 toast【待确认】。
