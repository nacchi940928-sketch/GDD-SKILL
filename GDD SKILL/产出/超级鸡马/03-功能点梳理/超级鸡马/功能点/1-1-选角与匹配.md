# 1-1 选角与匹配

## 涉及模块

| 模块 | 类型 | 说明 |
|------|------|------|
| 角色选择 UI | 新增 | 展示全部小鸟，仅可选已解锁 |
| 匹配服务 | 新增 | 段位池、放宽、组局 |
| 主界面入口 | 新增 | 开始游戏 → 选角 → 匹配 |

## 功能点

玩家从主界面进入「超级鸡马」：先在**选择角色界面**浏览所有小鸟卡牌，仅 **P-10 已解锁** 的可选中为 **P-11**；未解锁灰置不可选。确认后发起 **MatchStartReq**，进入匹配阶段。

**匹配规则**：
1. 优先 **P-14=0** 同段位池匹配；
2. 超时扩大到 **±1 段位**（P-14=1）；
3. 再超时扩大到 **任意段位**（P-14=2）；
4. 组局成功下发 **MatchSuccessNtf**，携带 **P-15** 对局 id、**P-16** 玩家列表、**P-18** 地图 id。

玩家可 **MatchCancelReq** 取消匹配，上报 **match_cancel**（取消时匹配耗时 = now - P-13）。

【待确认】T1/T2 放宽时间、房间人数上下限、匹配最终失败 UI。

## 数据来源

| P-xx | 用途 | 读/写 |
|------|------|-------|
| P-07 | 段位 | 读 |
| P-08 | MMR | 读 |
| P-10 | 已解锁小鸟 | 读 |
| P-11 | 本局选中鸟 | 读写 |
| P-12~P-14 | 匹配池状态 | 服务端 |
| P-15~P-18 | 对局初始化 | 写 |

## 怎么实现

### 通用
- 选角页加载 P-10，新解锁鸟触发 RD-CHH-002（见 10-1）。

### 服务端
```
on MatchStartReq:
  V-CHH-001 校验 P-11 ∈ P-10
  P-13 = now(), P-14 = 0
  enqueue(pool[P-07])
  loop R-CHH-002 直到成功或取消

on MatchCancelReq:
  dequeue, match_cancel 埋点
```

### 客户端
- 选角 UI：卡牌列表、确认按钮；
- 匹配 UI：搜索动画、取消按钮；
- MatchSuccessNtf → 加载对局场景 P-18。
