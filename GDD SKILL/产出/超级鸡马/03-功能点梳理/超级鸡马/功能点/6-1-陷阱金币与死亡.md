# 6-1 陷阱金币与死亡

## 涉及模块

| 模块 | 类型 | 说明 |
|------|------|------|
| 陷阱碰撞 | 新增 | 致死/非致死分层 |
| 地图原生陷阱 | 新增 | 周期触发 |
| 金币实体 | 新增 | 拾取/掉落/跟随 |

## 功能点

**死亡（一触即死）**：
- 玩家 hitbox 接触陷阱**致死 collider**（箭头、钉刺等）→ **P-33=false**；
- 箭杆等非致死部分不致死；
- 地图**原生陷阱**（始终或周期出现，各独立计时）可致死；
- 坠落出界 → FALL；
- 死亡表现：**灰色遮罩**；上报 **player_death**。

**金币**：
- 拾取：碰撞金币 → **P-35++**，金币跟随头顶显示；
- 死亡：**P-35** 枚金币生成 **P-36** 悬浮在死亡点（不受重力）；
- 其他玩家可再拾取；
- **仅带币到达终点**才计入该玩家金币相关成就分（**P-44**）。

**到达终点**：
- 存活玩家首次触达终点 → **P-37**=名次；第一名获速度分候选；
- **ReachGoalNtf**；**layer_finish** 埋点。

**P-05 结束**：未到达者 P-37=0 → 7-1 结算。

## 怎么实现

### 服务端
```
physics_tick:
  if lethal_overlap(player, trap): R-CHH-022
  if overlap(coin): R-CHH-023
  if overlap(goal) and P-33: R-CHH-024
```

### 客户端
- 陷阱动画（周期触发见道具表 trigger_period）；
- 金币跟随 UI；
- 死亡遮罩。
