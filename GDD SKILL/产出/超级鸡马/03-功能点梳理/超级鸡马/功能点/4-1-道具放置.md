# 4-1 道具放置

## 涉及模块

| 模块 | 类型 | 说明 |
|------|------|------|
| 放置预览 | 新增 | 网格吸附、附着、超长红区 |
| 放置校验 | 新增 | 服务端权威 |
| 物理配置 | 新增 | 重力/附着/蜂蜜 |

## 功能点

抢夺结束后立即开启 **P-04=30 秒** 放置倒计时，**P-17**=PROP_PLACE。

获得 **P-21** 的玩家须在限时内放置：
1. **摇杆**移动预览，道具**吸附网格**；
2. **确认键**发送 **PlacePropReq(P-24, P-25)**；
3. **不可修改**已确认位置。

**合法性**（失败则红色闪烁，客户端可预校验）：
- 不在出生/终点保护区（**P-47、P-48**）；
- 不与 **P-23** 已有道具重叠；
- 不与地图地形重叠；
- **P-28** 需附着时，必须满足附着条件；超长部分红色显示，放置后丢弃超出段；
- **P-27** 重力：跑酷开始时受重力/固定/随附着体；
- **蜂蜜**：邻接可 **P-29** 连接道具形成刚体组，不可连接者仅摆放不链接。

**结束**：全员 **P-32** 或 **P-04** 到 → 未放置者丢弃 P-21 → 进入跑酷。

## 怎么实现

### 客户端
```
update_preview(joystick):
  snap_to_grid()
  if overlap or protect_zone: show_red_flash()
  if attach_overflow: highlight_red_excess()

on confirm:
  PlacePropReq → 等 Rsp
  prop_place_success/fail 埋点
```

### 服务端
```
on PlacePropReq:
  V-CHH-003 / R-CHH-013
  append P-23, P-32=true
  if honey: R-CHH-014
```
