## 标准结构

```text
产出/{功能名}/
├── README.md
├── 补充与修改看板.md
├── 02-需求拆解.md           ← 单文档（8 维度 + 专项审计）
├── 03-功能点梳理.md         ← 单文档（程序主读）
├── 01-原始策划案/{功能名}/
│   ├── 原始策划案.md
│   └── 源表提取/          ← docx 内嵌表、提取稿备份（可选）
├── 04-待策划补充/{功能名}/
└── logs/                          ← 每次文档更新必写（见 使用指导 §4）
```

**占位符**：`{feature_root}` = `产出/{功能名}`
