## 标准结构

```text

├── README.md
├── 补充与修改看板.md
├── 02-03需求拆解与功能点梳理/

│   └── 源表提取/          ← docx 内嵌表备份（可选）
├── 04-待策划补充/{功能名}/

└── logs/
```

**占位符**：`{feature_root}` = `产出/{功能名}` · `{spec_root}` = `{feature_root}/02-03需求拆解与功能点梳理`
