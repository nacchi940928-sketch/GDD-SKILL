## 标准结构

```text
产出/{功能名}/
├── README.md
├── 补充与修改看板.md
├── 02-03需求拆解与功能点梳理/     ← P2/P3 拆解真源
│   ├── 02-需求拆解.md       ← 策划汇报（8 维度）
│   └── 03-功能点梳理.md     ← 程序主读
├── 01-原始策划案/{功能名}/
│   ├── 原始策划案.md
│   └── 源表提取/          ← docx 内嵌表、提取稿备份（可选）
├── 04-待策划补充/{功能名}/
├── 开发文档/                ← 程序包 / 测试包 / 策划包（compile 生成）
└── logs/                    ← 每次文档更新必写（见 使用指导 §4）
```

**占位符**：
- `{feature_root}` = `产出/{功能名}`
- `{spec_root}` = `{feature_root}/02-03需求拆解与功能点梳理`
