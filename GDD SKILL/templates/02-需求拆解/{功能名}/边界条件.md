# 边界条件

> **说明**
> 整理所有"不能做"的情况——什么条件下功能不可用、什么情况下会出错、硬限制是多少。
> 分三类：异常流程、前置条件、限制条件。

---

## 一、异常流程

| 编号 | 异常场景 | 触发条件 | 处理方式 | 用户提示 |
|------|----------|----------|----------|----------|
| EX-001 | | | | |

### 案例（参考：好友系统）

| 编号 | 异常场景 | 触发条件 | 处理方式 | 用户提示 |
|------|----------|----------|----------|----------|
| EX-FR-001 | 添加自己为好友 | 搜索自己的ID并发起申请 | 拒绝申请 | "不能添加自己为好友" |
| EX-FR-002 | 好友已满 | 己方或对方好友数=上限 | 拒绝申请 | "对方好友已满" |
| EX-FR-003 | 重复申请 | 已向同一玩家发送过待处理申请 | 拒绝，提示等待对方处理 | "已发送过好友申请" |
| EX-FR-004 | 被拉黑后申请 | 对方已将己方拉黑 | 静默拒绝，不通知对方 | 申请方显示"发送成功"但对方不可见 |
| EX-FR-005 | 删除好友时断线 | 删除操作发出后网络断开 | 服务端完成删除；重连后刷新列表 | — |

## 二、前置条件

| 编号 | 功能/操作 | 前置条件 | 不满足时行为 |
|------|-----------|----------|--------------|
| PRE-001 | | | |

### 案例（参考：好友系统）

| 编号 | 功能/操作 | 前置条件 | 不满足时行为 |
|------|-----------|----------|--------------|
| PRE-FR-001 | 发送好友申请 | 双方同一服务器 + 对方在线或存在 | 按钮置灰 |
| PRE-FR-002 | 私聊好友 | 双方互为好友 | 非好友不可私聊 |
| PRE-FR-003 | 赠送体力 | 互为好友 + 当日赠送次数未用完 | 按钮置灰+显示剩余次数 |
| PRE-FR-004 | 查看对方详情 | 对方隐私设置允许 | 显示"该玩家设置了隐私保护" |

## 三、限制条件

| 编号 | 限制项 | 类型 | 限制值 | 超限行为 |
|------|--------|------|--------|----------|
| LIM-001 | | | | |

### 案例（参考：好友系统）

| 编号 | 限制项 | 类型 | 限制值 | 超限行为 |
|------|--------|------|--------|----------|
| LIM-FR-001 | 好友数量 | 上限 | 100人 | 无法通过新申请；提示删除后再加 |
| LIM-FR-002 | 每日赠送体力 | 次数 | 20次/日 | 按钮置灰 |
| LIM-FR-003 | 待处理申请 | 上限 | 50条 | 最旧申请自动过期 |
| LIM-FR-004 | 黑名单数量 | 上限 | 50人 | 提示先移除部分再添加 |
| LIM-FR-005 | 好友申请冷却 | 冷却 | 同一目标24h内仅1次 | 拒绝 |
