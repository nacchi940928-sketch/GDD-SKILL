# 数据源

> **说明**
> 程序据此建表、写协议、定义枚举。字段名精确到类型和默认值。
> 所有字段统一用 P-xx 编号登记，禁止自创未确认的字段名。

---

## 一、配置表

| 表名 | 字段 | 类型 | 默认值 | 取值范围 | 说明 |
|------|------|------|--------|----------|------|
| | | | | | |

### 案例（参考：商店系统）

| 表名 | 字段 | 类型 | 默认值 | 取值范围 | 说明 |
|------|------|------|--------|----------|------|
| ShopConfig | shop_id | int | — | >0 | 商店ID（1=每日/2=每周/3=限时） |
| ShopConfig | refresh_utc | int | 0 | 0-23 | 刷新时间（UTC小时） |
| ShopItemConfig | item_id | int | — | >0 | 商品ID |
| ShopItemConfig | shop_id | int | — | >0 | 所属商店 |
| ShopItemConfig | reward_type | int | — | 1=道具/2=货币/3=碎片 | 奖励类型 |
| ShopItemConfig | reward_id | int | — | — | 奖励道具ID |
| ShopItemConfig | reward_count | int | 1 | >0 | 奖励数量 |
| ShopItemConfig | price_type | int | — | 1=金币/2=钻石/3=积分 | 货币类型 |
| ShopItemConfig | price | int | — | >0 | 价格 |
| ShopItemConfig | limit_type | int | 0 | 0=无限/1=日/2=周/3=总 | 限购类型 |
| ShopItemConfig | limit_count | int | -1 | -1=无限 | 限购次数 |
| ShopItemConfig | sort_weight | int | 0 | ≥0 | 排序权重（越大越前） |
