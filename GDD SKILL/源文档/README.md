# 源文档 — 策划原始 doc 存储

> **仅放原始策划文档**（docx / ppt 等），**不是**规格交付目录，**不是**「参考资料」目录。  
> 拆解产出（01 定稿、提取表、02 配置表）一律在 [`产出/`](../产出/)。

---

## 放什么

| 类型 | 示例 |
|------|------|
| 策划 **docx / ppt** | `《超级鸡马》.docx` |
| 会议纪要、口述整理（未进 01 前） | `xxx-会议纪要.md` |

## 不放什么

| 禁止 | 应放位置 |
|------|----------|
| docx **内嵌表 / 提取稿** | `产出/{功能名}/01-…/源表提取/` |
| 程序态配置表 | `产出/{功能名}/02-…/数据源/配置表/` |
| 01 定稿 | `产出/{功能名}/01-…/原始策划案.md` |
| 02/03/04 | `产出/{功能名}/` |
| 表关联 JSON 模板 | [`config/`](../config/) |
| 编译产出 | `outputs/{功能名}/` |

---

## 如何使用

1. 策划将 **docx** 放入本目录
2. **P1-1** `@源文档/xxx.docx` → 产出 `产出/{功能名}/01-…/原始策划案.md`
3. **P1/P2 提取内嵌 Excel** → 备份入 `产出/{功能名}/01-…/源表提取/`，程序态表写入 `02-…/配置表/`
4. **P2 及以后** 只 @ `产出/…/原始策划案.md` 与 02/03，不再 @ docx

详见 [使用指导.md](../使用指导.md)。
